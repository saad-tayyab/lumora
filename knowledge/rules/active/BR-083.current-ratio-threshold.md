# Current Ratio Threshold

## Statement

The current ratio should generally exceed 1.0 to indicate adequate liquidity; a ratio above 1.0 means current assets exceed current liabilities.

## Rationale

Provides a standardized measure of liquidity that can be compared across companies and periods.

## Conditions

- **WHEN** Evaluating short-term liquidity
- **THEN** Current Ratio = Current Assets / Current Liabilities; above 1.0 is generally favorable
- **OTHERWISE** A ratio below 1.0 may indicate difficulty meeting short-term obligations
