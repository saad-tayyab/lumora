# CVP Analysis Application to Services

## Statement

CVP analysis can be applied to service businesses by identifying service-specific variable and fixed costs, using service units (e.g., patient days, rides) as the activity base.

## Rationale

Service businesses face the same cost-volume-profit relationships as manufacturing businesses and can benefit from the same analytical tools.

## Conditions

- **WHEN** Performing CVP analysis for a service organization
- **THEN** Identify appropriate service activity base and classify costs as variable or fixed based on that base
- **OTHERWISE** CVP analysis will not accurately reflect the service business's cost structure
