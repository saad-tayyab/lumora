# Present Value Index Decision Rule

## Statement

Accept a project if the present value index is greater than 1.0. A project with a present value index of 0.75 does not meet the desired rate of return.

## Rationale

The present value index allows comparison of projects of different sizes by normalizing the present value relative to investment cost.

## Conditions

- **WHEN** Comparing projects of different investment sizes
- **THEN** Use present value index for ranking; accept if index > 1.0
- **OTHERWISE** NPV may be sufficient for ranking projects
