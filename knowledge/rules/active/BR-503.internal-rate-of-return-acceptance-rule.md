# Internal Rate of Return Acceptance Rule

## Statement

A capital investment proposal is acceptable if its internal rate of return equals or exceeds management's minimum required rate of return.

## Rationale

The IRR represents the actual rate of return earned by the investment; proposals earning at least the required rate create value.

## Conditions

- **WHEN** Evaluating a capital investment proposal using the IRR method
- **THEN** Accept if IRR >= minimum required rate; reject if IRR < minimum required rate
- **OTHERWISE** Use alternative evaluation methods
