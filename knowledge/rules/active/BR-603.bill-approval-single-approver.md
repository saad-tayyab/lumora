# Bill Approval Single Approver

## Statement

Vendor bills below the single_approver_threshold require only one approver before they can be paid.

## Rationale

This streamlines the approval process for low-value bills while maintaining proper authorization. Single approval for smaller amounts reduces processing overhead without compromising internal controls.

## Scope

- Applies to: All vendor bills (CON-AP-003) below single_approver_threshold
- Bounded Context: BC-AP (Accounts Payable)
- Entities: Bill, ApprovalWorkflow

## Conditions

- WHEN a vendor bill amount is less than or equal to single_approver_threshold
- THEN the bill requires exactly one authorized approver
- OTHERWISE the bill cannot transition to 'approved' status

## Pseudocode

```
function approveBill(bill, approver, policy):
    if bill.total_amount <= policy.single_approver_threshold:
        if approver.isAuthorized():
            bill.status = 'approved'
            bill.approved_by = approver.id
            bill.approved_at = currentTimestamp()
        else:
            throw UnauthorizedApproverError(approver.id)
    else:
        throw BillRequiresMultipleApproversError(bill.id)
```

## Exceptions

- None — this rule has no exceptions.
