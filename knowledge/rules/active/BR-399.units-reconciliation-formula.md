# Units Reconciliation Formula

## Statement

Units to account for = Beginning WIP units + Units started during the period. This must equal Units accounted for = Units completed + Ending WIP units.

## Rationale

Ensures all physical units are properly tracked through the production process.

## Conditions

- **WHEN** Preparing a cost of production report
- **THEN** Beginning WIP + Started = Completed + Ending WIP
- **OTHERWISE** Error in unit tracking
