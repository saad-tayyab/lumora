# Vertical Analysis Base Amount

## Statement

In vertical analysis of an income statement, all items are expressed as a percentage of sales (net revenue). In a balance sheet, all items are expressed as a percentage of total assets (or total liabilities and stockholders' equity).

## Rationale

Using consistent base amounts enables meaningful comparison across companies and periods.

## Conditions

- **WHEN** Preparing vertical analysis
- **THEN** Use sales as the base for income statement items, total assets for balance sheet items
- **OTHERWISE** Percentages are not comparable
