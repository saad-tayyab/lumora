# Invoice Currency Must Be Valid ISO Code

## Statement

The invoice currency must be a valid 3-letter ISO 4217 currency code.

## Rationale

Invalid currency codes would break reporting and payment processing.

## Conditions

- **WHEN an invoice is created
- THEN currency MUST be a valid ISO 4217 code
- OTHERWISE the creation is rejected with error code `ERR_INVOICE_INVALID_CURRENCY`**

## Pseudocode

```
function validateCurrency(invoice):
    if invoice.currency not in VALID_CURRENCIES:
        throw InvalidCurrencyError(invoice.id, invoice.currency)
```

None.
