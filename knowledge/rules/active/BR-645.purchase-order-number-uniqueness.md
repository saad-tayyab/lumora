# Purchase Order Number Uniqueness

## Statement

Purchase order numbers must be unique within a tenant.

## Rationale

Unique PO numbers are essential for proper identification, tracking, and referencing of purchase orders. Duplicate numbers would cause confusion and make it impossible to uniquely identify specific orders.

## Scope

- Applies to: All purchase orders (CON-PROC-002)
- Bounded Context: BC-PROC (Procurement)
- Entities: PurchaseOrder

## Conditions

- WHEN a purchase order is created
- THEN po_number MUST be unique within the tenant
- OTHERWISE the creation is rejected with error `ERR_PO_NUMBER_NOT_UNIQUE`

## Pseudocode

```
function validatePONumberUniqueness(po):
    existingPO = findPOByNumber(po.tenant_id, po.po_number)
    if existingPO != null AND existingPO.id != po.id:
        throw PONumberNotUniqueError(po.po_number)
```
