# Report Must Reference Data Source

## Statement

Every report must reference at least one data source.

## Rationale

A report without a data source has no content to display. Requiring at least one data source ensures reports are always meaningful and actionable.

## Scope

- Applies to: All reports (CON-REPORT-001)
- Bounded Context: BC-REPORT (Reporting & Analytics)
- Entities: Report, DataSource

## Conditions

- WHEN a report is created or activated
- THEN it MUST reference at least one valid data source
- OTHERWISE the report is rejected with error `ERR_REPORT_NO_DATA_SOURCE`

## Pseudocode

```
function validateReportDataSources(report):
    if report.dataSources == null OR report.dataSources.isEmpty():
        throw ReportNoDataSourceError(report.id)
```
