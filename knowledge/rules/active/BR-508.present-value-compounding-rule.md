# Present Value Compounding Rule

## Statement

A dollar today is worth more than a dollar in the future; the present value of a future amount is determined by discounting at the appropriate interest rate.

## Rationale

Money has earning potential through investment; present value analysis accounts for the time value of money in evaluating investments.

## Conditions

- **WHEN** Evaluating an investment using present value methods
- **THEN** Discount future cash flows to present value using the appropriate discount rate and time period
- **OTHERWISE** Use non-present-value methods (average rate of return, cash payback)
