# Bank Account Number Encryption

## Statement

Bank account numbers must be encrypted at rest in the database.

## Rationale

Bank account numbers are sensitive financial information. Encryption at rest protects against unauthorized access in case of database breaches and complies with financial data security regulations.

## Scope

- Applies to: All bank accounts (CON-CASH-001)
- Bounded Context: BC-CASH (Cash & Treasury)
- Entities: BankAccount

## Conditions

- WHEN a bank account number is stored in the database
- THEN the account_number field MUST be encrypted
- OTHERWISE the system violates financial data security requirements

## Pseudocode

```
function storeAccountNumber(account):
    // Encrypt account number before storage
    encryptedNumber = encrypt(account.account_number)
    account.account_number = encryptedNumber
    persist(account)

function retrieveAccountNumber(account):
    // Decrypt account number on retrieval
    decryptedNumber = decrypt(account.account_number)
    return decryptedNumber
```
