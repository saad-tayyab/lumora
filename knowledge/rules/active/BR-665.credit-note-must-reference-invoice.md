# Credit Note Must Reference Invoice

## Statement

Every credit note must reference at least one invoice.

## Rationale

Credit notes without invoice references would create unlinked adjustments that are difficult to audit.

## Conditions

- **WHEN a credit note is created
- THEN it MUST reference at least one invoice
- OTHERWISE the creation is rejected with error code `ERR_CREDIT_NOTE_NO_INVOICE`**

## Pseudocode

```
function validateCreditNote(creditNote):
    if not creditNote.invoiceId:
        throw CreditNoteNoInvoiceError(creditNote.id)
```

## Exceptions

None for standard credit notes.
