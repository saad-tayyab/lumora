# PO Approval Thresholds Configurable

## Statement

Purchase order approval thresholds are configurable per tenant.

## Rationale

Different organizations have different procurement authorization levels based on their size, industry, and risk tolerance. Configurable thresholds allow the system to adapt to various organizational structures.

## Scope

- Applies to: All purchase order approval policies (CON-PROC-014)
- Bounded Context: BC-PROC (Procurement)
- Entities: POApprovalPolicy

## Conditions

- WHEN the PO approval policy is configured
- THEN thresholds MUST be in ascending order (auto < manager < director < executive)
- OTHERWISE the configuration is rejected with error `ERR_PO_APPROVAL_THRESHOLDS_INVALID`

## Pseudocode

```
function validateApprovalThresholds(policy):
    if policy.auto_approval_threshold >= policy.manager_threshold:
        throw POApprovalThresholdsInvalidError('auto >= manager')
    
    if policy.manager_threshold >= policy.director_threshold:
        throw POApprovalThresholdsInvalidError('manager >= director')
    
    if policy.director_threshold >= policy.executive_threshold:
        throw POApprovalThresholdsInvalidError('director >= executive')
```

## Exceptions

- None — this rule has no exceptions.
