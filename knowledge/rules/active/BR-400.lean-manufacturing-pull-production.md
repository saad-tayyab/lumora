# Lean Manufacturing Pull Production

## Statement

In lean manufacturing, production pace should match customer demand (pull manufacturing) rather than using push scheduling based on demand estimates. This minimizes inventory levels and waste.

## Rationale

Reduces carrying costs, obsolescence risk, and improves cash flow by producing only what is needed.

## Conditions

- **WHEN** Implementing lean manufacturing principles
- **THEN** Use pull manufacturing to match production to actual demand
- **OTHERWISE** Push manufacturing leads to excess inventory
