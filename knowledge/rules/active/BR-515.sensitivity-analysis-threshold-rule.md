# Sensitivity Analysis Threshold Rule

## Statement

Sensitivity analysis should be used to determine the threshold values of key inputs (e.g., minimum annual cash flow, minimum useful life) at which the NPV becomes zero.

## Rationale

Identifying break-even thresholds helps management understand the margin of safety and the risk of the investment failing to meet objectives.

## Conditions

- **WHEN** There is uncertainty about key estimates in a capital investment analysis
- **THEN** Vary inputs one at a time and compute NPV for each scenario; identify the input level at which NPV = 0 as the threshold
- **OTHERWISE** Use base-case estimates only
