# Disposal Updates Depreciation First

## Statement

When disposing of an asset, depreciation must be updated to the disposal date before the disposal entry is posted.

## Rationale

Ensures the asset's accumulated depreciation is current at the time of disposal, so the gain or loss calculation reflects the true book value. Without this, the disposal gain/loss would be misstated.

## Scope

- Applies to: All fixed asset disposals (BC-ASSET)
- Bounded Context: BC-ASSET (Fixed Asset Management)
- Entities: FixedAsset, DepreciationEntry, AssetDisposal

## Conditions

- **WHEN** an asset disposal is initiated
- **THEN** the system MUST first post depreciation from the last depreciation date to the disposal date
- **OTHERWISE** the disposal entry must be rejected with error `ERR_DISPOSAL_DEPRECIATION_STALE`

## Pseudocode

```
function disposeAsset(assetId, disposalDate):
    asset = findFixedAsset(assetId)
    lastDepreciationDate = getLastDepreciationDate(assetId)
    
    if lastDepreciationDate < disposalDate:
        postDepreciation(asset, lastDepreciationDate, disposalDate)
    
    bookValue = calculateBookValue(assetId, disposalDate)
    recordDisposal(assetId, disposalDate, bookValue)
```

## Exceptions

- If the asset is land (non-depreciable), skip the depreciation update step.

## Related Rules

- INV-ASSET-004: Disposed assets must have depreciation updated to disposal date before removal
- BR-216: Depreciation method cannot change after asset is placed in service

## Related Concepts

- FixedAsset: A long-term tangible asset used in business operations
- DepreciationEntry: An accounting entry recording depreciation expense
- AssetDisposal: The removal of a fixed asset from the register
