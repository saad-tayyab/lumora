# Flexible Budget Comparison Rule

## Statement

When evaluating department performance, compare actual costs to flexible budget amounts (adjusted for actual activity level), not static budget amounts.

## Rationale

Static budgets do not account for changes in activity levels, leading to misleading variance analysis. Flexible budgets provide more accurate performance evaluation.

## Conditions

- **WHEN** Actual activity level differs from planned activity level
- **THEN** Use flexible budget to compute budgeted costs at actual activity level for comparison
- **OTHERWISE** Static budget may be used if actual activity matches planned activity
