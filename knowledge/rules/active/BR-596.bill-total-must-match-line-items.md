# Bill Total Must Match Line Items

## Statement

A vendor bill's total amount must equal the sum of all its line item amounts plus the tax amount.

## Rationale

This ensures financial integrity of vendor bills. The bill header total must be consistent with its line items to prevent data corruption and ensure accurate accounts payable records.

## Scope

- Applies to: All vendor bills (CON-AP-003)
- Bounded Context: BC-AP (Accounts Payable)
- Entities: Bill, BillLineItem

## Conditions

- WHEN a vendor bill is created or updated
- THEN total_amount MUST equal sum of all BillLineItem.amount values plus tax_amount
- OTHERWISE the bill is rejected with error `ERR_BILL_TOTAL_MISMATCH`

## Pseudocode

```
function validateBillTotal(bill):
    lineItemTotal = sum(bill.lineItems.map(item => item.amount))
    expectedTotal = lineItemTotal + bill.tax_amount
    
    if bill.total_amount != expectedTotal:
        throw BillTotalMismatchError(bill.id, bill.total_amount, expectedTotal)
```

## Exceptions

- None — this rule has no exceptions.
