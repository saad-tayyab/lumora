# Cannot Depreciate Below Residual Value

## Statement

Under all depreciation methods, an asset should not be depreciated below its estimated residual value.

## Rationale

Residual value represents the minimum value expected at end of useful life.

## Conditions

- **WHEN** Computing depreciation expense for any period
- **THEN** Ensure book value never falls below residual value
- **OTHERWISE** Adjust final year depreciation to bring book value to residual value
