# Salary Value Object Immutability

## Statement

Salary value objects are immutable. Changes to compensation must create a new Salary instance rather than modifying the existing one.

## Rationale

Immutability ensures a complete salary history for each employee. This is essential for payroll calculations, audit trails, and historical reporting. Previous salary records serve as the basis for back-pay calculations and compliance audits.

## Scope

- Applies to: All salary records (CON-HR-009)
- Bounded Context: BC-HR (Human Resources)
- Entities: Salary

## Conditions

- WHEN a salary change is requested
- THEN a NEW Salary instance MUST be created with the updated values
- OTHERWISE the system violates salary history integrity

## Pseudocode

```
function updateSalary(employeeId, newAmount, effectiveDate):
    // Mark current salary as inactive
    currentSalary = findActiveSalary(employeeId)
    currentSalary.is_active = false
    persist(currentSalary)
    
    // Create new salary instance
    newSalary = createSalary({
        base_amount: newAmount,
        effective_date: effectiveDate,
        is_active: true,
        // Copy other attributes from current salary
    })
    persist(newSalary)
```
