# Payment Amount Must Be Positive

## Statement

Every payment amount must be greater than zero.

## Rationale

Negative or zero payments are not meaningful and would corrupt financial records.

## Conditions

- **WHEN a payment is recorded
- THEN the amount MUST be > 0
- OTHERWISE the payment is rejected with error code `ERR_PAYMENT_INVALID_AMOUNT`**

## Pseudocode

```
function validatePaymentAmount(payment):
    if payment.amount <= 0:
        throw InvalidPaymentAmountError(payment.id, payment.amount)
```

## Exceptions

None.
