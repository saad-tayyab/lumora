# Completed Transfers Cannot Be Modified

## Statement

Completed bank transfers cannot be modified or deleted. They must retain their complete record for audit purposes.

## Rationale

Completed transfers represent finalized financial transactions. Modifying or deleting them would compromise the audit trail and could be used to conceal fraudulent activity. This is a critical internal control.

## Scope

- Applies to: All bank transfers (CON-CASH-002) in 'Completed' status
- Bounded Context: BC-CASH (Cash & Treasury)
- Entities: BankTransfer

## Conditions

- WHEN a bank transfer status is 'Completed'
- THEN the transfer record MUST NOT be modified or deleted
- OTHERWISE the system violates audit compliance requirements

## Pseudocode

```
function modifyTransfer(transfer):
    if transfer.status == 'Completed':
        throw CompletedTransferModificationError(transfer.id)
    // Proceed with modification only if not completed
```

## Exceptions

- None — this rule has no exceptions.
