# Dashboard Refresh Interval Bounds

## Statement

Dashboard refresh interval must be between 30 and 3600 seconds if set.

## Rationale

Refreshing too frequently (less than 30 seconds) wastes system resources and network bandwidth. Refreshing too infrequently (more than 3600 seconds) may provide stale data for time-sensitive dashboards.

## Scope

- Applies to: All dashboards (CON-REPORT-002) with refresh_interval_seconds set
- Bounded Context: BC-REPORT (Reporting & Analytics)
- Entities: Dashboard

## Conditions

- WHEN a dashboard refresh interval is configured
- THEN refresh_interval_seconds MUST be between 30 and 3600
- OTHERWISE the configuration is rejected with error `ERR_DASHBOARD_REFRESH_INTERVAL_INVALID`

## Pseudocode

```
function validateDashboardRefreshInterval(dashboard):
    if dashboard.refresh_interval_seconds != null:
        if dashboard.refresh_interval_seconds < 30 OR dashboard.refresh_interval_seconds > 3600:
            throw DashboardRefreshIntervalInvalidError(dashboard.id, dashboard.refresh_interval_seconds)
```

## Exceptions

- None — this rule has no exceptions.
