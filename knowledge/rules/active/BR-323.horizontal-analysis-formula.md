# Horizontal Analysis Formula

## Statement

Horizontal analysis computes the dollar change as current year amount minus base year amount, and the percentage change as dollar change divided by base year amount, expressed as a percentage.

## Rationale

This standardizes comparisons across different time periods and different-sized companies.

## Conditions

- **WHEN** Performing horizontal analysis on comparative financial statements
- **THEN** Compute dollar change = Current year - Base year; Percent change = Dollar change / Base year × 100
- **OTHERWISE** The analysis will not show the direction and magnitude of changes
