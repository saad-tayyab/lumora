# Purchase Order Self-Approval Prohibited

## Statement

The approver of a purchase order cannot be the same person who created the PO.

## Rationale

This enforces segregation of duties in procurement. Self-approval bypasses the intended oversight mechanism and increases the risk of fraudulent or unauthorized purchases.

## Scope

- Applies to: All purchase orders (CON-PROC-002)
- Bounded Context: BC-PROC (Procurement)
- Entities: PurchaseOrder

## Conditions

- WHEN a purchase order is approved
- THEN the approver MUST NOT be the same user who created the PO
- OTHERWISE the approval is rejected with error `ERR_PO_SELF_APPROVAL`

## Pseudocode

```
function approvePurchaseOrder(po, approver):
    if approver.id == po.created_by:
        throw POSelfApprovalError(po.id, approver.id)
    
    po.status = 'approved'
    po.approved_by = approver.id
    po.approved_at = currentTimestamp()
    persist(po)
```

## Exceptions

- None — this rule has no exceptions.
