# Voided Invoice Cannot Be Modified

## Statement

A voided invoice cannot have any fields modified or payments applied.

## Rationale

Voided invoices are historical records and must not be altered.

## Conditions

- **WHEN an update is attempted on a voided invoice
- THEN the update MUST be rejected
- OTHERWISE with error code `ERR_INVOICE_VOIDED`**

## Pseudocode

```
function validateNotVoided(invoice):
    if invoice.status == 'voided':
        throw VoidedInvoiceModificationError(invoice.id)
```

## Exceptions

None.
