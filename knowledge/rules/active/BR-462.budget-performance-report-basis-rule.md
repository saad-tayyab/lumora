# Budget Performance Report Basis Rule

## Statement

The budget performance report must be based on actual units produced, not the originally planned production volume.

## Rationale

Comparing actual costs to budget at the original volume would mix volume effects with cost control effects, making variance analysis meaningless.

## Conditions

- **WHEN** Preparing a budget performance report
- **THEN** Compute standard costs using actual production volume (Standard Cost per Unit × Actual Units Produced)
- **OTHERWISE** Variances will not accurately reflect cost control performance
