# Credit Limit Check on Invoice Creation

## Statement

When creating an invoice, the customer's total outstanding balance plus the new invoice total must not exceed the customer's credit limit.

## Rationale

Prevents extending excessive credit to customers and manages bad debt risk.

## Conditions

- **WHEN an invoice is created for a customer with a credit limit
- THEN (customer.totalOutstanding + invoice.totalAmount) MUST be <= customer.creditLimit
- OTHERWISE the creation is blocked with error code `ERR_CUSTOMER_CREDIT_LIMIT_EXCEEDED`**

## Pseudocode

```
function checkCreditLimit(invoice):
    customer = getCustomer(invoice.customerId)
    if customer.creditLimit is not null:
        outstanding = getCustomerOutstanding(customer.id)
        if outstanding + invoice.totalAmount > customer.creditLimit:
            throw CreditLimitExceededError(
                customer.id, outstanding + invoice.totalAmount, customer.creditLimit
            )
```

## Exceptions

Manually overridden by authorized users with a documented reason.
