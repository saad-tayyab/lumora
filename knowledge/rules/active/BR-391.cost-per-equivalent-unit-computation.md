# Cost Per Equivalent Unit Computation

## Statement

Cost per equivalent unit = Total cost for the category divided by Total equivalent units for the category. This is computed separately for direct materials and conversion costs.

## Rationale

Provides the unit cost used to assign costs to completed units and ending inventory.

## Conditions

- **WHEN** Equivalent units have been computed
- **THEN** Cost per equivalent unit = Total cost / Equivalent units
- **OTHERWISE** Cannot compute unit cost
