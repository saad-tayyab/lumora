# Average Rate of Return Calculation

## Statement

The average rate of return is computed as average annual income divided by average investment: ARR = Average Annual Income / ((Initial Cost + Residual Value) / 2).

## Rationale

This metric provides a simple percentage return measure based on accounting income rather than cash flows.

## Conditions

- **WHEN** Evaluating project profitability using accrual-based income
- **THEN** Compute ARR using the formula
- **OTHERWISE** Use cash flow-based methods like NPV or payback
