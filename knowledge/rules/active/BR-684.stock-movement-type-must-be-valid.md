# Stock Movement Type Must Be Valid

## Statement

Stock movement type must be one of: purchase, sale, transfer_in, transfer_out, adjustment, return_in, return_out.

## Rationale

Invalid movement types would corrupt inventory tracking.

## Conditions

- **WHEN a stock movement is created
- THEN movementType MUST be one of the valid types
- OTHERWISE the movement is rejected with error code `ERR_MOVEMENT_INVALID_TYPE`**

## Pseudocode

```
VALID_TYPES = ['purchase', 'sale', 'transfer_in', 'transfer_out', 'adjustment', 'return_in', 'return_out']

function validateMovementType(movement):
    if movement.movementType not in VALID_TYPES:
        throw InvalidMovementTypeError(movement.id, movement.movementType)
```

## Exceptions

None.
