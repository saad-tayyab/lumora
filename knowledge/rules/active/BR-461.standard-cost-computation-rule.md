# Standard Cost Computation Rule

## Statement

Standard cost per unit = Standard Price × Standard Quantity for each cost element (direct materials, direct labor, manufacturing overhead).

## Rationale

Standard costs provide a benchmark for evaluating actual performance by separating price and efficiency components.

## Conditions

- **WHEN** Computing standard cost per unit for a product
- **THEN** Multiply standard price by standard quantity for each cost element and sum
- **OTHERWISE** Standard costs cannot be established for performance evaluation
