# Customer Must Be Active to Place Orders

## Statement

An invoice cannot be created for a customer with isActive = false.

## Rationale

Inactive customers should not have new financial obligations.

## Conditions

- **WHEN an invoice is created
- THEN the customer.isActive MUST be true
- OTHERWISE the creation is rejected with error code `ERR_CUSTOMER_INACTIVE`**

## Pseudocode

```
function validateCustomerActive(invoice):
    customer = getCustomer(invoice.customerId)
    if not customer.isActive:
        throw CustomerInactiveError(customer.id)
```

## Exceptions

None.
