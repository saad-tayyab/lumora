# Gain Recognized When Exchange Has Commercial Substance

## Statement

If an exchange of similar assets has commercial substance, a gain is recognized when the trade-in allowance exceeds the book value of the old asset.

## Rationale

Commercial substance means future cash flows change, so the economic substance of the transaction justifies gain recognition under GAAP.

## Conditions

- **WHEN** Exchange of similar assets has commercial substance AND trade-in allowance > book value
- **THEN** Recognize gain equal to trade-in allowance minus book value of old asset
- **OTHERWISE** If no commercial substance, no gain is recognized (gain is deferred by reducing new asset cost)
