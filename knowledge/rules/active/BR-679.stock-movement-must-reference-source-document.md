# Stock Movement Must Reference Source Document

## Statement

Every stock movement must reference a source document (invoice, purchase order, transfer order, etc.).

## Rationale

Ensures traceability and audit trail for all inventory changes.

## Conditions

- **WHEN a stock movement is created
- THEN sourceDocumentType and sourceDocumentId MUST be provided
- OTHERWISE the movement is rejected with error code `ERR_MOVEMENT_NO_SOURCE`**

## Pseudocode

```
function validateStockMovement(movement):
    if not movement.sourceDocumentType or not movement.sourceDocumentId:
        throw MovementNoSourceDocumentError(movement.id)
```

## Exceptions

Initial stock count (opening balance) may use 'opening_balance' as source document type.
