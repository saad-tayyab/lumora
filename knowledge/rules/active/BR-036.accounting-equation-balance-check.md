# Accounting Equation Balance Check

## Statement

When solving for a missing element in the accounting equation, the equation must always balance: Assets = Liabilities + Owner's Equity.

## Rationale

The accounting equation is the foundation of double-entry accounting and must hold true at all times.

## Conditions

- **WHEN** Any element of the accounting equation is unknown
- **THEN** Solve for the unknown using algebra: if Assets unknown, A = L + OE; if Liabilities unknown, L = A - OE; if OE unknown, OE = A - L
- **OTHERWISE** The equation will not balance, indicating an error
