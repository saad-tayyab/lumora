# Invoice Status Transitions Are Restricted

## Statement

An invoice can only transition to valid next states based on its current status.

## Rationale

Prevents invalid state changes such as voiding a paid invoice or recording payment on a draft invoice.

## Conditions

- **WHEN an invoice status change is requested
- THEN the transition MUST follow the allowed state machine
- OTHERWISE the change is rejected with error code `ERR_INVOICE_INVALID_STATUS_TRANSITION`**

## Pseudocode

```
ALLOWED_TRANSITIONS = {
    'draft': ['sent', 'voided'],
    'sent': ['paid', 'overdue', 'voided'],
    'overdue': ['paid', 'voided'],
    'paid': ['voided'],
    'voided': []
}

function validateStatusTransition(invoice, newStatus):
    allowed = ALLOWED_TRANSITIONS[invoice.status]
    if newStatus not in allowed:
        throw InvalidStatusTransitionError(invoice.id, invoice.status, newStatus)
```

## Exceptions

Only administrators can void a paid invoice.
