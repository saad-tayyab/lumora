# Direct vs Indirect Cost Tracing

## Statement

A cost should be classified as direct if it can be easily and conveniently traced to a cost object. If tracing is impractical or cost-prohibitive, it is classified as indirect.

## Rationale

Balances accuracy of cost allocation with cost-benefit of tracing.

## Conditions

- **WHEN** A cost is associated with a cost object
- **THEN** Determine if it can be conveniently traced
- **OTHERWISE** Classify as indirect cost and allocate using an appropriate base
