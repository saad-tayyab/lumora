# Credit Note Amount Must Be Positive

## Statement

The credit note amount must be greater than zero.

## Rationale

Zero or negative credit notes are not meaningful.

## Conditions

- **WHEN a credit note is created
- THEN the amount MUST be > 0
- OTHERWISE the creation is rejected with error code `ERR_CREDIT_NOTE_INVALID_AMOUNT`**

## Pseudocode

```
function validateCreditNoteAmount(creditNote):
    if creditNote.amount <= 0:
        throw InvalidCreditNoteAmountError(creditNote.id, creditNote.amount)
```

## Exceptions

None.
