# Purchase Order Cannot Be Modified After Approval

## Statement

A purchase order cannot be modified after it has been approved.

## Rationale

Approved purchase orders represent committed procurement obligations. Modifying them after approval would compromise the audit trail and could lead to unauthorized changes in procurement terms.

## Scope

- Applies to: All purchase orders (CON-PROC-002) in 'approved' status
- Bounded Context: BC-PROC (Procurement)
- Entities: PurchaseOrder

## Conditions

- WHEN a purchase order status is 'approved'
- THEN the PO record MUST NOT be modified
- OTHERWISE the system violates audit compliance requirements

## Pseudocode

```
function modifyPurchaseOrder(po):
    if po.status == 'approved':
        throw ApprovedPOModificationError(po.id)
    // Proceed with modification only if not approved
```

## Exceptions

- None — this rule has no exceptions.
