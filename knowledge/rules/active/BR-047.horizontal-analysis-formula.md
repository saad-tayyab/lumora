# Horizontal Analysis Formula

## Statement

Amount of Change = Current Period Amount - Base Period Amount. Percent of Change = (Amount of Change / Base Period Amount) × 100.

## Rationale

Provides a standardized method for comparing financial data across periods.

## Conditions

- **WHEN** Performing horizontal analysis on financial statements
- **THEN** Compute the dollar change and percentage change for each line item using the formulas
- **OTHERWISE** Comparisons will be inconsistent
