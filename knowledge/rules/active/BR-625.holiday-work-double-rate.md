# Holiday Work Double Rate

## Statement

Work performed on designated holidays must be compensated at 2x the regular hourly rate.

## Rationale

Holiday premium pay compensates employees for working on designated holidays when they would normally be off. The double rate reflects the additional inconvenience and is often required by labor regulations.

## Scope

- Applies to: All attendance records (CON-HR-004) on designated holidays
- Bounded Context: BC-HR (Human Resources)
- Entities: Attendance, OvertimePolicy

## Conditions

- WHEN an employee works on a designated holiday
- THEN all hours worked MUST be compensated at holiday_multiplier (default 2.0) times the regular hourly rate
- OTHERWISE the employee is underpaid for holiday work

## Pseudocode

```
function calculateHolidayPay(attendance, salary, policy):
    if isHoliday(attendance.date):
        regularHourlyRate = salary.base_amount / standardMonthlyHours
        holidayRate = regularHourlyRate * policy.holiday_multiplier
        holidayPay = attendance.hours_worked * holidayRate
        return holidayPay
    else:
        return calculateRegularPay(attendance, salary)
```

## Exceptions

- None — this rule has no exceptions.
