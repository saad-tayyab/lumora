# Periodic Refresh Requires Valid Interval

## Statement

Data sources with periodic refresh type must have a valid positive interval configured.

## Rationale

Periodic refresh without a valid interval would either fail to schedule or create invalid refresh schedules. A positive interval ensures predictable and reliable data updates.

## Scope

- Applies to: All data refresh policies (CON-REPORT-014) with refresh_type = 'periodic'
- Bounded Context: BC-REPORT (Reporting & Analytics)
- Entities: DataRefreshPolicy

## Conditions

- WHEN a data refresh policy with refresh_type = 'periodic' is created or updated
- THEN interval_seconds MUST be a positive integer
- OTHERWISE the policy is rejected with error `ERR_REFRESH_INTERVAL_REQUIRED`

## Pseudocode

```
function validateRefreshPolicy(policy):
    if policy.refresh_type == 'periodic':
        if policy.interval_seconds == null OR policy.interval_seconds <= 0:
            throw RefreshIntervalRequiredError(policy.policy_id)
```
