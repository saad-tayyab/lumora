# Payment Must Have Payment Method

## Statement

Every payment must specify a valid payment method.

## Rationale

Payment method is required for proper accounting treatment and reconciliation.

## Conditions

- **WHEN a payment is created
- THEN paymentMethod MUST be one of: cash, check, credit_card, bank_transfer, other
- OTHERWISE the creation is rejected with error code `ERR_PAYMENT_INVALID_METHOD`**

## Pseudocode

```
VALID_METHODS = ['cash', 'check', 'credit_card', 'bank_transfer', 'other']

function validatePaymentMethod(payment):
    if payment.paymentMethod not in VALID_METHODS:
        throw InvalidPaymentMethodError(payment.id, payment.paymentMethod)
```

## Exceptions

None.
