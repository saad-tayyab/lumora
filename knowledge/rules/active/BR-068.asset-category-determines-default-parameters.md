# Asset Category Determines Default Parameters

## Statement

When creating a new asset, the default depreciation method and useful life are inherited from the asset category unless explicitly overridden.

## Rationale

Ensures consistency in depreciation treatment within asset categories while allowing flexibility for exceptional cases. Reduces manual data entry and minimizes configuration errors.

## Scope

- Applies to: All new fixed asset creation (BC-ASSET)
- Bounded Context: BC-ASSET (Fixed Asset Management)
- Entities: FixedAsset, AssetCategory

## Conditions

- **WHEN** a new fixed asset is created
- **THEN** the depreciation method and useful life MUST be inherited from the asset category
- **AND** these values MAY be overridden by the user if explicitly provided
- **OTHERWISE** the asset is created with category defaults

## Pseudocode

```
function createAsset(assetData):
    category = findAssetCategory(assetData.category_id)
    
    asset = {
        ...assetData,
        depreciation_method: assetData.depreciation_method ?? category.default_depreciation_method,
        useful_life: assetData.useful_life ?? category.default_useful_life,
        salvage_value: assetData.salvage_value ?? category.default_salvage_value
    }
    
    persist(asset)
```

## Exceptions

- User-provided depreciation method and useful life override category defaults when explicitly supplied.

## Related Rules

- None

## Related Concepts

- FixedAsset: A long-term tangible asset used in business operations
- AssetCategory: A classification grouping assets with shared depreciation defaults
