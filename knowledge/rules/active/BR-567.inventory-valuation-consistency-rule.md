# Inventory Valuation Consistency Rule

## Statement

Once an inventory cost flow method (FIFO, LIFO, or weighted average) is adopted, it must be used consistently unless a change is properly disclosed.

## Rationale

Consistency ensures comparability of financial statements across periods.

## Conditions

- **WHEN** Accounting for inventory cost flows
- **THEN** Apply the same inventory method consistently each period
- **OTHERWISE** Financial statements become non-comparable and violate GAAP
