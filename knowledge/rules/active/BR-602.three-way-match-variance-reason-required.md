# Three-Way Match Variance Reason Required

## Statement

When a three-way match fails (is_matched is false), a variance reason must be provided explaining the discrepancies.

## Rationale

This ensures accountability and traceability when vendor bills do not match purchase orders and receiving reports. Documenting the reason for variances supports audit trails and helps resolve discrepancies.

## Scope

- Applies to: All three-way match results (CON-AP-006)
- Bounded Context: BC-AP (Accounts Payable)
- Entities: ThreeWayMatchResult

## Conditions

- WHEN a three-way match result is created with is_matched = false
- THEN variance_reason MUST be provided and not empty
- OTHERWISE the match result is rejected with error `ERR_VARIANCE_REASON_REQUIRED`

## Pseudocode

```
function validateThreeWayMatch(matchResult):
    if matchResult.is_matched == false AND (matchResult.variance_reason == null OR matchResult.variance_reason.isEmpty()):
        throw VarianceReasonRequiredError(matchResult.bill_id)
```

## Exceptions

- None — this rule has no exceptions.
