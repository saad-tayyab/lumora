# Discount Percentage Bounds

## Statement

Discount percentage values must be between 0 and 100 inclusive.

## Rationale

Percentages outside the 0-100 range are mathematically invalid for discount calculations. A 0% discount means no discount, while 100% means free (which may require special approval).

## Scope

- Applies to: All discount policies (CON-SALES-007) with type = 'Percentage'
- Bounded Context: BC-SALES (Sales & Orders)
- Entities: DiscountPolicy

## Conditions

- WHEN a percentage discount policy is created or updated
- THEN value MUST be between 0 and 100 inclusive
- OTHERWISE the policy is rejected with error `ERR_DISCOUNT_PERCENTAGE_INVALID`

## Pseudocode

```
function validateDiscountPercentage(policy):
    if policy.type == 'Percentage':
        if policy.value < 0 OR policy.value > 100:
            throw DiscountPercentageInvalidError(policy.policy_id, policy.value)
```
