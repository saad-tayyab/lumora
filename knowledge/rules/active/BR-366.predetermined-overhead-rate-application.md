# Predetermined Overhead Rate Application

## Statement

Manufacturing overhead is applied to jobs using a predetermined overhead rate calculated before the period begins. Applied OH = Predetermined Rate × Actual Activity Base.

## Rationale

Allows timely cost estimation for jobs before actual overhead costs are known.

## Conditions

- **WHEN** Overhead costs need to be assigned to jobs
- **THEN** Apply using the predetermined rate and actual activity
- **OTHERWISE** Jobs do not carry overhead costs
