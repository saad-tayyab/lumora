# Bill Approval Executive Approval

## Statement

Vendor bills above the escalation_threshold require executive approval before they can be paid.

## Rationale

This ensures high-value payments receive appropriate executive oversight. Executive approval for large amounts provides the highest level of authorization and reduces financial risk.

## Scope

- Applies to: All vendor bills (CON-AP-003) above escalation_threshold
- Bounded Context: BC-AP (Accounts Payable)
- Entities: Bill, ApprovalWorkflow

## Conditions

- WHEN a vendor bill amount is greater than escalation_threshold
- THEN the bill requires executive approval
- OTHERWISE the bill cannot transition to 'approved' status

## Pseudocode

```
function approveBill(bill, approver, policy):
    if bill.total_amount > policy.escalation_threshold:
        if approver.isExecutive():
            bill.status = 'approved'
            bill.approved_by = approver.id
            bill.approved_at = currentTimestamp()
        else:
            throw ExecutiveApprovalRequiredError(bill.id, bill.total_amount)
    else:
        throw BillThresholdMismatchError(bill.id)
```

## Exceptions

- None — this rule has no exceptions.
