# Book Value Not Market Value

## Statement

The book value of a fixed asset (cost minus accumulated depreciation) does not necessarily represent the asset's fair market value.

## Rationale

Depreciation is an allocation of cost, not a valuation of the asset.

## Conditions

- **WHEN** Reviewing a balance sheet with fixed assets
- **THEN** Book value is reported, which may differ significantly from market value
- **OTHERWISE** Users may mistakenly believe book value equals market value
