# Single Active Fee Policy Per Tenant

## Statement

Only one bank fee policy can be active per tenant at a time.

## Rationale

Multiple active fee policies would create ambiguity in fee detection and categorization. A single active policy ensures consistent application of fee rules across all statement imports and reconciliation operations within a tenant.

## Scope

- Applies to: All bank fee policies (CON-CASH-016)
- Bounded Context: BC-CASH (Cash & Treasury)
- Entities: BankFeePolicy

## Conditions

- WHEN a new bank fee policy is activated
- THEN all other fee policies for the same tenant MUST be deactivated
- OTHERWISE the system violates the single active policy constraint

## Pseudocode

```
function activateFeePolicy(newPolicy):
    // Deactivate all other policies for this tenant
    existingPolicies = findActiveFeePoliciesByTenant(newPolicy.tenant_id)
    for policy in existingPolicies:
        policy.is_active = false
        persist(policy)
    
    newPolicy.is_active = true
    persist(newPolicy)
```

## Exceptions

- None — this rule has no exceptions.
