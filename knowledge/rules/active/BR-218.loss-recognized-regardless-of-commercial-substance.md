# Loss Recognized Regardless of Commercial Substance

## Statement

If an exchange of similar assets results in a loss (trade-in allowance < book value), the loss is recognized regardless of whether the exchange has commercial substance.

## Rationale

Losses are recognized immediately to avoid overstating asset values on the balance sheet.

## Conditions

- **WHEN** Exchange of similar assets where trade-in allowance < book value
- **THEN** Recognize loss equal to book value minus trade-in allowance
- **OTHERWISE** If trade-in allowance >= book value, apply gain recognition rules
