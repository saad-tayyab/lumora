# Gain Can Be Computed Two Ways

## Statement

Gain on exchange can be determined either as: (1) trade-in allowance of old asset minus book value of old asset, or (2) fair market value of new asset minus (book value of old asset + cash paid). Both methods yield the same result.

## Rationale

Both approaches measure the same economic benefit from the exchange transaction.

## Conditions

- **WHEN** Computing gain on exchange with commercial substance
- **THEN** Either method is acceptable; both produce identical results
- **OTHERWISE** N/A
