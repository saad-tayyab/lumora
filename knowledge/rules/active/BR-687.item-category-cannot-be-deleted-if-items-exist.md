# Item Category Cannot Be Deleted If Items Exist

## Statement

An item category cannot be deleted if it has any items assigned to it.

## Rationale

Deleting a category with items would orphan those items.

## Conditions

- **WHEN a category deletion is requested
- THEN the system MUST check for items with that categoryId
- IF items exist, the deletion MUST be rejected with error code `ERR_CATEGORY_HAS_ITEMS`**

## Pseudocode

```
function validateCategoryDeletion(category):
    itemCount = countItemsByCategory(category.id)
    if itemCount > 0:
        throw CategoryHasItemsError(category.id, itemCount)
```

## Exceptions

Soft deletion (setting isActive = false) is always allowed.
