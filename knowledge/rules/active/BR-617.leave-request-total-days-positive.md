# Leave Request Total Days Positive

## Statement

A leave request's total days must be a positive integer.

## Rationale

Zero or negative leave days are meaningless and would cause errors in leave balance calculations and payroll processing. This ensures valid leave period representation.

## Scope

- Applies to: All leave requests (CON-HR-005)
- Bounded Context: BC-HR (Human Resources)
- Entities: LeaveRequest

## Conditions

- WHEN a leave request is created or updated
- THEN total_days MUST be greater than zero
- OTHERWISE the leave request is rejected with error `ERR_LEAVE_TOTAL_DAYS_INVALID`

## Pseudocode

```
function validateLeaveTotalDays(leaveRequest):
    if leaveRequest.total_days <= 0:
        throw LeaveTotalDaysInvalidError(leaveRequest.id, leaveRequest.total_days)
```

## Exceptions

- None — this rule has no exceptions.
