# No Overlapping Payroll Runs

## Statement

No two payroll runs can overlap for the same period within a tenant.

## Rationale

Overlapping payroll runs would create duplicate compensation records, leading to double payments and accounting errors. Each pay period must be processed exactly once.

## Scope

- Applies to: All payroll runs (CON-HR-007)
- Bounded Context: BC-HR (Human Resources)
- Entities: Payroll

## Conditions

- WHEN a new payroll run is created
- THEN the period must NOT overlap with any existing payroll run for the same tenant
- OTHERWISE the payroll run is rejected with error `ERR_PAYROLL_PERIOD_OVERLAP`

## Pseudocode

```
function validatePayrollPeriod(payroll):
    existingPayrolls = findPayrollsByTenant(payroll.tenant_id)
    for existing in existingPayrolls:
        if periodsOverlap(payroll.period_start, payroll.period_end, existing.period_start, existing.period_end):
            throw PayrollPeriodOverlapError(payroll.id, existing.id)
```

## Exceptions

- None — this rule has no exceptions.
