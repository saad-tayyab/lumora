# Employee Must Belong To One Department

## Statement

Every employee must belong to exactly one department.

## Rationale

Department assignment is essential for organizational structure, reporting hierarchies, and cost center allocation. An employee without a department cannot be properly managed or have their costs attributed correctly.

## Scope

- Applies to: All employees (CON-HR-001)
- Bounded Context: BC-HR (Human Resources)
- Entities: Employee, Department

## Conditions

- WHEN an employee is created or updated
- THEN department_id MUST reference exactly one valid department
- OTHERWISE the employee record is rejected with error `ERR_EMPLOYEE_DEPARTMENT_REQUIRED`

## Pseudocode

```
function validateEmployeeDepartment(employee):
    if employee.department_id == null:
        throw EmployeeDepartmentRequiredError(employee.id)
    
    department = findDepartment(employee.department_id)
    if department == null:
        throw DepartmentNotFoundError(employee.department_id)
```
