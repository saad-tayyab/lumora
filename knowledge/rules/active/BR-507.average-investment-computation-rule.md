# Average Investment Computation Rule

## Statement

Average investment is computed as (Initial Cost + Residual Value) / 2.

## Rationale

This represents the average amount of capital tied up in the asset over its useful life, assuming straight-line depreciation to residual value.

## Conditions

- **WHEN** Computing the average rate of return
- **THEN** Average Investment = (Initial Cost + Residual Value) / 2
- **OTHERWISE** N/A
