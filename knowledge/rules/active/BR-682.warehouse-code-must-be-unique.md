# Warehouse Code Must Be Unique

## Statement

Every warehouse must have a unique code within the tenant.

## Rationale

Warehouse codes are used in reports, labels, and API references.

## Conditions

- **WHEN a warehouse is created or updated
- THEN the code MUST be unique across all warehouses in the tenant
- OTHERWISE the operation is rejected with error code `ERR_WAREHOUSE_DUPLICATE_CODE`**

## Pseudocode

```
function validateWarehouseCode(warehouse):
    existing = findWarehouseByCode(warehouse.code, warehouse.tenantId)
    if existing and existing.id != warehouse.id:
        throw DuplicateWarehouseCodeError(warehouse.code)
```

## Exceptions

None.
