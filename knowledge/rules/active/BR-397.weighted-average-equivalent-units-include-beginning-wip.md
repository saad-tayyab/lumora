# Weighted Average Equivalent Units Include Beginning WIP

## Statement

Under the weighted average method, equivalent units include all work done to date on units in beginning work in process, not just the work done in the current period.

## Rationale

The weighted average method blends prior period work with current period work to simplify cost calculations.

## Conditions

- **WHEN** Using weighted average method for process costing
- **THEN** Equivalent units = Units completed + (Ending WIP x Percent complete)
- **OTHERWISE** Use FIFO method which separates prior period work
