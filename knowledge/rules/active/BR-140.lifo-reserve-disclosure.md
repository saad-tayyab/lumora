# LIFO Reserve Disclosure

## Statement

When LIFO is used and ending inventory on the balance sheet differs significantly from current replacement cost, financial statements normally include a note estimating what the inventory would have been if FIFO had been used.

## Rationale

LIFO can result in inventory values on the balance sheet that are materially different from current replacement cost, requiring disclosure for users of the financial statements.

## Conditions

- **WHEN** Using LIFO and inventory differs significantly from replacement cost
- **THEN** Disclose the difference in a note to the financial statements
- **OTHERWISE** Users may be misled about the current value of inventory
