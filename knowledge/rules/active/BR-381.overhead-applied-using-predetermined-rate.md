# Overhead Applied Using Predetermined Rate

## Statement

Manufacturing overhead is applied to jobs by multiplying the predetermined overhead rate by the actual activity base (e.g., machine hours, direct labor hours) used by the job.

## Rationale

Provides timely cost information without waiting for actual overhead costs to be determined at period end.

## Conditions

- **WHEN** Production activity occurs during the period
- **THEN** Apply overhead = Predetermined Rate × Actual Activity for the job
- **OTHERWISE** No overhead applied
