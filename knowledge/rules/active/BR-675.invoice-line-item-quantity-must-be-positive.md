# Invoice Line Item Quantity Must Be Positive

## Statement

Every invoice line item must have a quantity greater than zero.

## Rationale

Zero or negative quantities would create invalid line items.

## Conditions

- **WHEN an invoice line item is created or updated
- THEN quantity MUST be > 0
- OTHERWISE the line item is rejected with error code `ERR_LINE_ITEM_INVALID_QUANTITY`**

## Pseudocode

```
function validateLineItemQuantity(lineItem):
    if lineItem.quantity <= 0:
        throw InvalidLineItemQuantityError(lineItem.id, lineItem.quantity)
```

## Exceptions

None.
