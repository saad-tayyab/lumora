# Stock Movement Quantity Must Be Positive

## Statement

Every stock movement quantity must be greater than zero. Direction is indicated by movement type (in/out/transfer).

## Rationale

Zero or negative quantities on movements are not meaningful.

## Conditions

- **WHEN a stock movement is created
- THEN quantity MUST be > 0
- OTHERWISE the movement is rejected with error code `ERR_MOVEMENT_INVALID_QUANTITY`**

## Pseudocode

```
function validateMovementQuantity(movement):
    if movement.quantity <= 0:
        throw InvalidMovementQuantityError(movement.id, movement.quantity)
```

## Exceptions

None.
