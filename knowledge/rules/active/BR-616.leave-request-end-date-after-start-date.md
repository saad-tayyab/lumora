# Leave Request End Date After Start Date

## Statement

A leave request's end date must be on or after the start date.

## Rationale

This ensures logical consistency of leave requests. A leave period cannot end before it begins, which would create invalid date ranges for absence tracking and payroll calculations.

## Scope

- Applies to: All leave requests (CON-HR-005)
- Bounded Context: BC-HR (Human Resources)
- Entities: LeaveRequest

## Conditions

- WHEN a leave request is created or updated
- THEN end_date MUST be on or after start_date
- OTHERWISE the leave request is rejected with error `ERR_LEAVE_DATE_RANGE_INVALID`

## Pseudocode

```
function validateLeaveDates(leaveRequest):
    if leaveRequest.end_date < leaveRequest.start_date:
        throw LeaveDateRangeError(leaveRequest.id, leaveRequest.start_date, leaveRequest.end_date)
```

## Exceptions

- None — this rule has no exceptions.
