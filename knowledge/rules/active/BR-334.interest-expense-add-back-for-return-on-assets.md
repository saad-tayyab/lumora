# Interest Expense Add-Back for Return on Assets

## Statement

Interest expense is added back to net income when computing return on total assets.

## Rationale

Adding interest expense eliminates the effect of whether assets are financed by debt or equity, providing a measure independent of financing decisions.

## Conditions

- **WHEN** Computing return on total assets
- **THEN** Add interest expense to net income in the numerator
- **OTHERWISE** Return on total assets is biased by financing structure
