# Favorable vs Unfavorable Variance Classification Rule

## Statement

A variance is favorable when actual cost is less than standard cost (credit); a variance is unfavorable when actual cost exceeds standard cost (debit).

## Rationale

Classifying variances as favorable or unfavorable provides immediate directional information about cost control performance.

## Conditions

- **WHEN** Analyzing any cost variance
- **THEN** If actual < standard, classify as favorable; if actual > standard, classify as unfavorable
- **OTHERWISE** Variance analysis will not indicate whether costs were higher or lower than expected
