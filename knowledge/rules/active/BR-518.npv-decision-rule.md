# NPV Decision Rule

## Statement

Accept a capital investment project if its net present value is positive (NPV > 0) at the desired rate of return.

## Rationale

A positive NPV indicates the project generates returns exceeding the required rate, creating value for the organization.

## Conditions

- **WHEN** NPV > 0
- **THEN** Project is acceptable and should be accepted
- **OTHERWISE** Project should be rejected
