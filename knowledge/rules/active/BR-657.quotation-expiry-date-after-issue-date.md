# Quotation Expiry Date After Issue Date

## Statement

A quotation's expiry date must be after the issue date.

## Rationale

A quotation cannot expire before it is issued. This temporal constraint ensures logical consistency of quotation validity periods.

## Scope

- Applies to: All quotations (CON-SALES-004)
- Bounded Context: BC-SALES (Sales & Orders)
- Entities: Quotation, QuotationExpiryPolicy

## Conditions

- WHEN a quotation is created or updated
- THEN expiry_date MUST be after issue_date
- OTHERWISE the quotation is rejected with error `ERR_QUOTATION_EXPIRY_BEFORE_ISSUE`

## Pseudocode

```
function validateQuotationDates(quotation):
    if quotation.expiry_date <= quotation.issue_date:
        throw QuotationExpiryBeforeIssueError(quotation.id, quotation.expiry_date, quotation.issue_date)
```

## Exceptions

- None — this rule has no exceptions.
