# Reorder Point Triggers Alert

## Statement

When stock level for an item in a warehouse falls below or equal to the reorder point, a reorder alert should be generated.

## Rationale

Automated reordering prevents stockouts and ensures business continuity.

## Conditions

- **WHEN a stock movement reduces stock level
- AND new quantity <= item.reorderPoint
- THEN a reorder alert MUST be generated
- AND notification sent to procurement team**

## Pseudocode

```
function checkReorderPoint(item, warehouse):
    stockLevel = getStockLevel(item.id, warehouse.id)
    if stockLevel.quantity <= item.reorderPoint:
        createReorderAlert(item, warehouse, stockLevel.quantity)
        notifyProcurement(item, warehouse)
```

## Exceptions

If item.autoReorder is disabled, no alert is generated.
