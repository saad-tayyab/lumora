# Archived Reports Cannot Be Modified

## Statement

Archived reports cannot be modified or regenerated. They represent historical snapshots and must remain unchanged.

## Rationale

Archived reports serve as historical records for compliance and audit purposes. Modifying them would compromise data integrity and could violate regulatory requirements.

## Scope

- Applies to: All reports (CON-REPORT-001) in 'archived' status
- Bounded Context: BC-REPORT (Reporting & Analytics)
- Entities: Report

## Conditions

- WHEN a report status is 'archived'
- THEN the report MUST NOT be modified or regenerated
- OTHERWISE the system violates data integrity requirements

## Pseudocode

```
function modifyReport(report):
    if report.status == 'archived':
        throw ArchivedReportModificationError(report.id)
    // Proceed with modification only if not archived
```

## Exceptions

- None — this rule has no exceptions.
