# Credit Note Status Transitions Are Restricted

## Statement

A credit note can only transition to valid next states based on its current status.

## Rationale

Prevents invalid state changes on credit notes.

## Conditions

- **WHEN a credit note status change is requested
- THEN the transition MUST follow the allowed state machine
- OTHERWISE the change is rejected with error code `ERR_CREDIT_NOTE_INVALID_STATUS_TRANSITION`**

## Pseudocode

```
ALLOWED_CREDIT_NOTE_TRANSITIONS = {
    'draft': ['issued'],
    'issued': []
}

function validateCreditNoteStatusTransition(creditNote, newStatus):
    allowed = ALLOWED_CREDIT_NOTE_TRANSITIONS[creditNote.status]
    if newStatus not in allowed:
        throw InvalidCreditNoteStatusError(creditNote.id, creditNote.status, newStatus)
```

## Exceptions

None.
