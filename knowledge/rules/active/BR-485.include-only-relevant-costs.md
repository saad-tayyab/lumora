# Include Only Relevant Costs

## Statement

Only differential costs and revenues that differ between alternatives should be included in differential analysis.

## Rationale

Costs that are the same under all alternatives do not affect the decision and should be ignored.

## Conditions

- **WHEN** Analyzing alternatives
- **THEN** Include only costs and revenues that differ between alternatives
- **OTHERWISE** Analysis will include irrelevant information
