# Only Manager Can Approve Leave

## Statement

Only an employee's direct manager (referenced via manager_id) can approve or reject a leave request.

## Rationale

This ensures proper authorization and segregation of duties in the leave approval process. Managers are responsible for their team's attendance and must approve time off to maintain operational coverage.

## Scope

- Applies to: All leave requests (CON-HR-005)
- Bounded Context: BC-HR (Human Resources)
- Entities: LeaveRequest, Employee, LeaveApprovalPolicy

## Conditions

- WHEN a leave request is submitted for approval
- THEN the approver MUST be the employee's direct manager
- OTHERWISE the approval is rejected with error `ERR_UNAUTHORIZED_LEAVE_APPROVER`

## Pseudocode

```
function approveLeaveRequest(leaveRequest, approver):
    employee = findEmployee(leaveRequest.employee_id)
    
    if approver.id != employee.manager_id:
        throw UnauthorizedLeaveApproverError(leaveRequest.id, approver.id, employee.manager_id)
    
    leaveRequest.status = 'Approved'
    leaveRequest.approver_id = approver.id
    leaveRequest.approval_date = currentTimestamp()
    persist(leaveRequest)
```

## Exceptions

- If the manager is unavailable, approval can be delegated to a higher-level manager in the same department hierarchy.
