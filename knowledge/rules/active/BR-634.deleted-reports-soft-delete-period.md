# Deleted Reports Soft-Delete Period

## Statement

Deleted reports are soft-deleted for 30 days before permanent removal.

## Rationale

Soft deletion provides a recovery window for accidentally deleted reports. The 30-day period balances storage efficiency with the need for data recovery in case of errors.

## Scope

- Applies to: All reports (CON-REPORT-001) marked for deletion
- Bounded Context: BC-REPORT (Reporting & Analytics)
- Entities: Report

## Conditions

- WHEN a report is marked for deletion
- THEN it MUST be soft-deleted for 30 days before permanent removal
- OTHERWISE there is no recovery window for accidentally deleted reports

## Pseudocode

```
function deleteReport(report):
    report.deleted_at = currentTimestamp()
    report.status = 'archived'
    persist(report)

function permanentDeletionJob():
    cutoffDate = currentTimestamp() - 30.days
    expiredReports = findSoftDeletedReportsBefore(cutoffDate)
    for report in expiredReports:
        hardDelete(report)
```

## Exceptions

- None — this rule has no exceptions.
