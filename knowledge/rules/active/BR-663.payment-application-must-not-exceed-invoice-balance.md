# Payment Application Must Not Exceed Invoice Balance

## Statement

The total amount applied to an invoice cannot exceed the invoice balance due.

## Rationale

Prevents overpayment and ensures payment applications are mathematically valid.

## Conditions

- **WHEN a payment is applied to an invoice
- THEN the applied amount MUST be <= invoice.balanceDue
- OTHERWISE the application is rejected with error code `ERR_PAYMENT_EXCEEDS_BALANCE`**

## Pseudocode

```
function validatePaymentApplication(invoice, application):
    if application.amountApplied > invoice.balanceDue:
        throw PaymentExceedsBalanceError(
            invoice.id, application.amountApplied, invoice.balanceDue
        )
```

## Exceptions

Credit notes can create negative balances on the invoice.
