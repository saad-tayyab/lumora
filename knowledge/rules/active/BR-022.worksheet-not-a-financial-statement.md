# Worksheet Not a Financial Statement

## Statement

The worksheet is an internal tool for accountants and is not part of the formal financial statements.

## Rationale

The worksheet helps organize data but is not distributed to external users.

## Conditions

- **WHEN** Preparing the worksheet
- **THEN** Use it as a planning and organizing tool only
- **OTHERWISE** Internal working papers may be confused with external reports
