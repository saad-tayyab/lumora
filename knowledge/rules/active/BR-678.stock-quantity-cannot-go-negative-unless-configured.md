# Stock Quantity Cannot Go Negative Unless Configured

## Statement

Stock quantity for any item in any warehouse cannot go below zero unless the tenant has enabled negative stock in configuration.

## Rationale

Negative stock would indicate selling items that don't exist, which is a critical data integrity issue.

## Conditions

- **WHEN a stock movement would reduce stock below zero
- THEN the movement MUST be rejected unless tenant config allows negative stock
- OTHERWISE with error code `ERR_STOCK_INSUFFICIENT`**

## Pseudocode

```
function validateStockLevel(item, warehouse, quantityChange):
    current = getStockLevel(item.id, warehouse.id)
    newLevel = current.quantity + quantityChange
    if newLevel < 0 and not tenant.config.allowNegativeStock:
        throw InsufficientStockError(item.id, warehouse.id, current.quantity, abs(quantityChange))
```

## Exceptions

Tenant configuration `allowNegativeStock` can override this rule.
