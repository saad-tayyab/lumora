# Employee Must Have One Designation

## Statement

Every employee must have exactly one designation.

## Rationale

Designation defines the employee's role and responsibilities within the organization. A designation is required for proper job classification, salary determination, and approval authority assignment.

## Scope

- Applies to: All employees (CON-HR-001)
- Bounded Context: BC-HR (Human Resources)
- Entities: Employee, Designation

## Conditions

- WHEN an employee is created or updated
- THEN designation_id MUST reference exactly one valid designation
- OTHERWISE the employee record is rejected with error `ERR_EMPLOYEE_DESIGNATION_REQUIRED`

## Pseudocode

```
function validateEmployeeDesignation(employee):
    if employee.designation_id == null:
        throw EmployeeDesignationRequiredError(employee.id)
    
    designation = findDesignation(employee.designation_id)
    if designation == null:
        throw DesignationNotFoundError(employee.designation_id)
```

## Exceptions

- None — this rule has no exceptions.
