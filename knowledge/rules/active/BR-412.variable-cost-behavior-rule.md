# Variable Cost Behavior Rule

## Statement

Variable cost per unit remains constant regardless of changes in the activity base, while total variable cost changes in direct proportion to changes in the activity base.

## Rationale

Understanding this behavior is essential for CVP analysis and predicting how costs change with volume.

## Conditions

- **WHEN** Analyzing cost behavior within the relevant range
- **THEN** Variable cost per unit is constant; total variable cost is proportional to activity
- **OTHERWISE** Cost predictions will be inaccurate
