# Weighted Average Cost Includes Beginning WIP Costs

## Statement

Under the weighted average method, the cost per equivalent unit is computed by dividing total costs (beginning WIP costs + current period costs) by total equivalent units.

## Rationale

Provides a smoothed average cost that includes both prior and current period costs.

## Conditions

- **WHEN** Computing cost per equivalent unit under weighted average
- **THEN** Cost per unit = (Beginning WIP cost + Current period cost) / Total equivalent units
- **OTHERWISE** Use FIFO method which only uses current period costs
