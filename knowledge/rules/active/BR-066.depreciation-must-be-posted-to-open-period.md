# Depreciation Must Be Posted to Open Period

## Statement

Depreciation entries must only be posted to accounting periods that are in 'open' status.

## Rationale

Posting depreciation to closed or non-existent periods would compromise the integrity of financial reporting. Only open periods guarantee that the depreciation expense is recorded in the correct accounting timeframe and can be reviewed before period close.

## Scope

- Applies to: All depreciation entry postings (BC-ASSET)
- Bounded Context: BC-ASSET (Fixed Asset Management)
- Entities: DepreciationEntry, AccountingPeriod

## Conditions

- **WHEN** a depreciation entry is posted
- **THEN** the target accounting period MUST have status 'open'
- **OTHERWISE** the posting must be rejected with error `ERR_DEPRECIATION_CLOSED_PERIOD`

## Pseudocode

```
function postDepreciationEntry(entry, periodId):
    period = findAccountingPeriod(periodId)
    
    if period.status != 'open':
        throw DepreciationClosedPeriodError(entry.asset_id, periodId)
    
    entry.period_id = periodId
    entry.posted_at = currentTimestamp()
    persist(entry)
```

## Exceptions

- None — this rule has no exceptions.
