# Audit Log Entries Retained Indefinitely

## Statement

Audit log entries for deleted reports must be retained indefinitely, even after the report itself is permanently removed.

## Rationale

Audit logs provide an immutable record of system activities. Retaining them indefinitely ensures compliance with regulatory requirements and supports forensic investigations regardless of when they occur.

## Scope

- Applies to: All audit log entries related to report deletion
- Bounded Context: BC-REPORT (Reporting & Analytics)
- Entities: Report (audit logs)

## Conditions

- WHEN a report is permanently deleted
- THEN all audit log entries for that report MUST be retained indefinitely
- OTHERWISE the system violates audit compliance requirements

## Pseudocode

```
function permanentDeletionJob():
    expiredReports = findSoftDeletedReportsBefore(cutoffDate)
    for report in expiredReports:
        // Audit logs are never deleted
        auditLogs = findAuditLogsByReport(report.id)
        // Report is deleted but audit logs remain
        hardDelete(report)
```

## Exceptions

- None — this rule has no exceptions.
