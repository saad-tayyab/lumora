# KPI Threshold Breach Triggers Event

## Statement

When a KPI value breaches its warning or critical threshold, a KPIBreached event must be emitted.

## Rationale

Threshold breaches indicate business conditions that require attention. Emitting events enables automated notifications, dashboard updates, and downstream processing to address the breach.

## Scope

- Applies to: All KPIs (CON-REPORT-003)
- Bounded Context: BC-REPORT (Reporting & Analytics)
- Entities: KPI, KPIBreached

## Conditions

- WHEN a KPI's current_value breaches warning_threshold or critical_threshold
- THEN a KPIBreached event MUST be emitted
- OTHERWISE stakeholders are not notified of the threshold breach

## Pseudocode

```
function evaluateKPIThresholds(kpi):
    if kpi.current_value >= kpi.critical_threshold:
        emitKPIBreached(kpi, 'critical')
    else if kpi.current_value >= kpi.warning_threshold:
        emitKPIBreached(kpi, 'warning')
```

## Exceptions

- None — this rule has no exceptions.
