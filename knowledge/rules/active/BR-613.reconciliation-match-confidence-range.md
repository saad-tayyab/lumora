# Reconciliation Match Confidence Range

## Statement

Reconciliation match confidence scores must be between 0.0 and 1.0 inclusive.

## Rationale

Confidence scores represent a probability or certainty level. Values outside the 0.0-1.0 range are mathematically invalid and would produce incorrect matching decisions in the reconciliation process.

## Scope

- Applies to: All reconciliation matches (CON-CASH-005) and entries (CON-CASH-004)
- Bounded Context: BC-CASH (Cash & Treasury)
- Entities: ReconciliationMatch, ReconciliationEntry

## Conditions

- WHEN a reconciliation match confidence score is set
- THEN the value MUST be between 0.0 and 1.0 inclusive
- OTHERWISE the match is rejected with error `ERR_CONFIDENCE_SCORE_INVALID`

## Pseudocode

```
function validateConfidenceScore(match):
    if match.confidence_score < 0.0 OR match.confidence_score > 1.0:
        throw ConfidenceScoreInvalidError(match.statement_entry_id, match.confidence_score)
```

## Exceptions

- None — this rule has no exceptions.
