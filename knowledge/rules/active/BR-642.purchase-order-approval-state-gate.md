# Purchase Order Approval State Gate

## Statement

A purchase order can only be approved when its status is 'pending_approval'.

## Rationale

This enforces proper state transitions in the PO lifecycle. Only POs that have been submitted and are awaiting approval can be approved, preventing premature or unauthorized approvals.

## Scope

- Applies to: All purchase orders (CON-PROC-002)
- Bounded Context: BC-PROC (Procurement)
- Entities: PurchaseOrder, POStatus

## Conditions

- WHEN a purchase order approval is requested
- THEN the PO status MUST be 'pending_approval'
- OTHERWISE the approval is rejected with error `ERR_PO_INVALID_APPROVAL_STATE`

## Pseudocode

```
function approvePurchaseOrder(po):
    if po.status != 'pending_approval':
        throw POInvalidApprovalStateError(po.id, po.status)
    
    po.status = 'approved'
    po.approved_at = currentTimestamp()
    persist(po)
```

## Exceptions

- None — this rule has no exceptions.
