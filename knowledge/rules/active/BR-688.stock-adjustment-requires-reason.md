# Stock Adjustment Requires Reason

## Statement

Stock adjustment movements must include a reason field explaining the adjustment.

## Rationale

Adjustments without reasons are difficult to audit and may indicate fraud.

## Conditions

- **WHEN a stock adjustment movement is created
- THEN reason MUST be provided
- OTHERWISE the adjustment is rejected with error code `ERR_ADJUSTMENT_NO_REASON`**

## Pseudocode

```
function validateAdjustmentReason(movement):
    if movement.movementType == 'adjustment' and not movement.reason:
        throw AdjustmentNoReasonError(movement.id)
```

## Exceptions

None.
