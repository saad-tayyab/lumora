# Terminated Employee Cannot Request Leave

## Statement

A leave request cannot be approved for an employee with 'Terminated' status.

## Rationale

Terminated employees are no longer active in the organization and should not be eligible for leave. Approving leave for terminated employees would create incorrect absence records and potential payroll errors.

## Scope

- Applies to: All leave requests (CON-HR-005)
- Bounded Context: BC-HR (Human Resources)
- Entities: LeaveRequest, Employee

## Conditions

- WHEN a leave request is submitted for approval
- THEN the employee's status MUST NOT be 'Terminated'
- OTHERWISE the leave request is rejected with error `ERR_LEAVE_TERMINATED_EMPLOYEE`

## Pseudocode

```
function approveLeaveRequest(leaveRequest):
    employee = findEmployee(leaveRequest.employee_id)
    if employee.status == 'Terminated':
        throw TerminatedEmployeeLeaveError(leaveRequest.id, employee.id)
```

## Exceptions

- None — this rule has no exceptions.
