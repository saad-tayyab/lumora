# Error Correction Requires Identifying Root Cause

## Statement

Before correcting an error in the trial balance, the specific type and cause of the error must be identified. Each error type requires a different corrective action.

## Rationale

盲目地调整数字 without understanding the error type can introduce additional errors. Systematic identification ensures the correct account and amount are adjusted.

## Conditions

- **WHEN** A trial balance discrepancy or incorrect balance is detected
- **THEN** Identify the error type (overstatement, omission, posting error, transposition) before making corrections
- **OTHERWISE** Incorrect corrections may compound the original error
