# Standard Quantity Based on Actual Production

## Statement

Variances must be computed by comparing actual costs to standard costs adjusted for actual production volume, not planned production volume.

## Rationale

Using actual production ensures variances reflect true performance differences rather than volume differences.

## Conditions

- **WHEN** Computing direct materials and direct labor variances
- **THEN** Use standard quantity allowed for actual units produced
- **OTHERWISE** Variances would mix volume and efficiency effects
