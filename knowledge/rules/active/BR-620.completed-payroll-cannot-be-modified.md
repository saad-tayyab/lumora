# Completed Payroll Cannot Be Modified

## Statement

A payroll run cannot be modified once its status is 'Completed'.

## Rationale

Completed payroll runs represent finalized compensation transactions. Modifying them would compromise the audit trail, create accounting discrepancies, and potentially violate labor regulations.

## Scope

- Applies to: All payroll runs (CON-HR-007) in 'Completed' status
- Bounded Context: BC-HR (Human Resources)
- Entities: Payroll

## Conditions

- WHEN a payroll run status is 'Completed'
- THEN the payroll record MUST NOT be modified
- OTHERWISE the system violates audit compliance requirements

## Pseudocode

```
function modifyPayroll(payroll):
    if payroll.status == 'Completed':
        throw CompletedPayrollModificationError(payroll.id)
    // Proceed with modification only if not completed
```

## Exceptions

- None — this rule has no exceptions.
