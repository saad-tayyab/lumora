# Net Present Value Acceptance Rule

## Statement

A capital investment proposal is acceptable if its net present value is zero or positive, meaning the present value of cash inflows equals or exceeds the amount to be invested.

## Rationale

A positive NPV indicates the investment earns more than the minimum required rate of return, creating value for the organization.

## Conditions

- **WHEN** Evaluating a capital investment proposal using the net present value method
- **THEN** Accept if NPV >= 0; reject if NPV < 0
- **OTHERWISE** Use alternative evaluation methods
