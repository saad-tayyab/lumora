# Multiple Budget Lines Per GL Account

## Statement

A budget header may have multiple budget lines for the same GL account (e.g., different cost centers or projects).

## Rationale

Organizations often need to track budget allocations for the same GL account across different departments, projects, or cost centers. Supporting multiple lines per account enables granular budget tracking and reporting without duplicating GL accounts.

## Scope

- Applies to: All budget line creation within a budget header (BC-BUDGET)
- Bounded Context: BC-BUDGET (Budget Management)
- Entities: BudgetHeader, BudgetLine

## Conditions

- **WHEN** a new budget line is added to a budget header
- **THEN** the system MUST allow multiple lines referencing the same GL account
- **AND** each line MUST have a unique combination of GL account, cost center, and project (if applicable)
- **OTHERWISE** the budget line creation must be rejected with error `ERR_BUDGET_DUPLICATE_LINE`

## Pseudocode

```
function addBudgetLine(headerId, lineData):
    existingLines = findBudgetLines(headerId, lineData.gl_account_id)
    
    duplicate = existingLines.find(line =>
        line.cost_center_id == lineData.cost_center_id &&
        line.project_id == lineData.project_id
    )
    
    if duplicate:
        throw DuplicateBudgetLineError(headerId, lineData)
    
    line = {
        header_id: headerId,
        ...lineData
    }
    persist(line)
```

## Exceptions

- A GL account may only appear once per cost center/project combination within a single budget header.
