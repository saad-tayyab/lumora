# Units Started and Completed Formula

## Statement

Units started and completed = Units completed and transferred out minus beginning work in process units. This represents units that were both started and finished within the current period.

## Rationale

Separates current period production from work done on beginning inventory in prior periods.

## Conditions

- **WHEN** Computing started and completed units for FIFO
- **THEN** Started and completed = Completed - Beginning WIP
- **OTHERWISE** Use alternative: Started and completed = Started - Ending WIP
