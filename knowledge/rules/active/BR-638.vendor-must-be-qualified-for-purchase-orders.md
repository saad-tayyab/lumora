# Vendor Must Be Qualified For Purchase Orders

## Statement

A vendor must be qualified before they can receive purchase orders.

## Rationale

Vendor qualification ensures only approved suppliers participate in procurement. This prevents orders to unqualified vendors who may not meet quality, compliance, or financial standards.

## Scope

- Applies to: All purchase orders (CON-PROC-002)
- Bounded Context: BC-PROC (Procurement)
- Entities: PurchaseOrder, Vendor, VendorQualificationPolicy

## Conditions

- WHEN a purchase order is created
- THEN the vendor MUST pass all qualification rules (VENDOR-001 to VENDOR-004)
- OTHERWISE the purchase order is rejected with error `ERR_VENDOR_NOT_QUALIFIED`

## Pseudocode

```
function validateVendorQualification(po, vendor, policy):
    if vendor.status != 'active':
        throw VendorNotQualifiedError(po.id, vendor.id, 'inactive status')
    
    if vendor.tax_id == null OR vendor.tax_id.isEmpty():
        throw VendorNotQualifiedError(po.id, vendor.id, 'missing tax ID')
    
    if vendor.onboarding_complete != true:
        throw VendorNotQualifiedError(po.id, vendor.id, 'onboarding incomplete')
    
    if isSuspendedOrBlacklisted(vendor):
        throw VendorNotQualifiedError(po.id, vendor.id, 'suspended or blacklisted')
```
