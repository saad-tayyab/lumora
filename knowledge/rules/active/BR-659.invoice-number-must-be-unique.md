# Invoice Number Must Be Unique

## Statement

Every invoice must have a globally unique invoice number within the tenant.

## Rationale

Invoice numbers serve as the primary reference for customers, vendors, and auditors. Duplicate numbers would cause confusion and compliance violations.

## Conditions

- **WHEN a new invoice is created
- THEN the invoice number MUST be unique across all invoices in the tenant
- OTHERWISE the creation is rejected with error code `ERR_INVOICE_DUPLICATE_NUMBER`**

## Pseudocode

```
function validateInvoiceNumber(invoice):
    existing = findInvoiceByNumber(invoice.invoiceNumber, invoice.tenantId)
    if existing:
        throw DuplicateInvoiceNumberError(invoice.invoiceNumber)
```

## Exceptions

None — uniqueness is absolute within a tenant.
