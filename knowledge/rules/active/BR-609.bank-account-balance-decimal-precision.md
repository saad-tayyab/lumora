# Bank Account Balance Decimal Precision

## Statement

Bank account balances must be stored with decimal precision (numeric type) and never as floating point numbers.

## Rationale

Floating point arithmetic introduces rounding errors that accumulate over time, leading to inaccurate financial records. Decimal precision ensures exact representation of monetary values as required by accounting standards.

## Scope

- Applies to: All bank accounts (CON-CASH-001)
- Bounded Context: BC-CASH (Cash & Treasury)
- Entities: BankAccount

## Conditions

- WHEN a bank account balance is stored or updated
- THEN the value MUST use numeric/decimal type with appropriate precision
- OTHERWISE the system risks financial calculation errors

## Pseudocode

```
function storeBalance(account, amount):
    // Ensure decimal precision - never use float
    if type(amount) == float:
        throw FloatingPointBalanceError(account.id)
    account.current_balance = amount
    persist(account)
```

## Exceptions

- None — this rule has no exceptions.
