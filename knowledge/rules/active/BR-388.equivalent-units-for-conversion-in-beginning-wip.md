# Equivalent Units for Conversion in Beginning WIP

## Statement

Beginning work in process inventory equivalent units for conversion costs are based on the percentage of conversion work remaining to be done in the current period. If beginning WIP was 70% complete, only the remaining 30% is counted as current period equivalent units.

## Rationale

Only the work performed in the current period is counted under the FIFO method.

## Conditions

- **WHEN** Beginning WIP exists with a given completion percentage
- **THEN** Equivalent units = Whole units x (100% - Beginning % complete)
- **OTHERWISE** No beginning inventory to process
