# Voided Bill Audit Retention

## Statement

Voided vendor bills must retain their complete record for audit purposes and must not be hard-deleted from the system.

## Rationale

Financial regulations require maintaining a complete audit trail of all vendor bill transactions, including voided bills. This ensures compliance with accounting standards and supports audit investigations.

## Scope

- Applies to: All vendor bills (CON-AP-003) in voided status
- Bounded Context: BC-AP (Accounts Payable)
- Entities: Bill

## Conditions

- WHEN a vendor bill status transitions to 'voided'
- THEN the bill record MUST be retained with all historical data
- OTHERWISE the system violates audit compliance requirements

## Pseudocode

```
function voidBill(bill):
    bill.status = 'voided'
    bill.voided_at = currentTimestamp()
    bill.voided_by = currentUser()
    // Never delete the bill record
    persist(bill)
```

## Exceptions

- None — this rule has no exceptions.
