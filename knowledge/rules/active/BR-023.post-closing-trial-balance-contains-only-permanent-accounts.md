# Post-Closing Trial Balance Contains Only Permanent Accounts

## Statement

The post-closing trial balance should contain only permanent (balance sheet) accounts since all temporary accounts have been closed.

## Rationale

Verifies that the ledger is in balance after closing and that only permanent accounts carry forward.

## Conditions

- **WHEN** Preparing the post-closing trial balance
- **THEN** Include only assets, liabilities, and equity accounts
- **OTHERWISE** An error exists in the closing process
