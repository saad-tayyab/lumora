# Budget Consumption Reverses on Void

## Statement

When a journal entry that consumed budget is voided, the corresponding budget consumption record must be reversed.

## Rationale

Ensures budget consumption figures remain accurate when source transactions are voided. Without reversal, budget reporting would show phantom consumption that no longer corresponds to actual spending.

## Scope

- Applies to: All voided journal entries that consumed budget (BC-BUDGET)
- Bounded Context: BC-BUDGET (Budget Management)
- Entities: BudgetConsumption, JournalEntry

## Conditions

- **WHEN** a journal entry that consumed budget is voided
- **THEN** the corresponding budget consumption record MUST be reversed
- **AND** the budget line available amount MUST be restored
- **OTHERWISE** the budget consumption data is inconsistent with actual transactions

## Pseudocode

```
function voidJournalEntry(entryId):
    entry = findJournalEntry(entryId)
    consumption = findBudgetConsumption(entryId)
    
    if consumption:
        consumption.amount = -consumption.amount
        consumption.reversed_at = currentTimestamp()
        consumption.reversal_entry_id = entryId
        persist(consumption)
        
        budgetLine = findBudgetLine(consumption.budget_line_id)
        budgetLine.consumed_amount -= consumption.amount
        persist(budgetLine)
    
    entry.status = 'voided'
    persist(entry)
```

## Exceptions

- If the budget period is closed, the reversal must be posted to the next open period.
