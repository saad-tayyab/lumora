# Transfer Source Different From Destination

## Statement

A bank transfer's source account must be different from its destination account.

## Rationale

This prevents nonsensical self-transfers that would waste processing resources and create confusing transaction records. Internal fund movements between the same account serve no business purpose.

## Scope

- Applies to: All bank transfers (CON-CASH-002)
- Bounded Context: BC-CASH (Cash & Treasury)
- Entities: BankTransfer, BankAccount

## Conditions

- WHEN a bank transfer is created
- THEN source_account_id MUST NOT equal destination_account_id
- OTHERWISE the transfer is rejected with error `ERR_TRANSFER_SAME_ACCOUNT`

## Pseudocode

```
function validateTransferAccounts(transfer):
    if transfer.source_account_id == transfer.destination_account_id:
        throw TransferSameAccountError(transfer.id, transfer.source_account_id)
```

## Exceptions

- None — this rule has no exceptions.
