# Credit Note Amount Cannot Exceed Invoice Balance

## Statement

The credit note amount cannot exceed the remaining balance of the referenced invoice.

## Rationale

Prevents issuing more credit than the invoice is worth.

## Conditions

- **WHEN a credit note is created for an invoice
- THEN creditNote.amount MUST be <= invoice.balanceDue
- OTHERWISE the creation is rejected with error code `ERR_CREDIT_NOTE_EXCEEDS_INVOICE`**

## Pseudocode

```
function validateCreditNoteAgainstInvoice(creditNote, invoice):
    if creditNote.amount > invoice.balanceDue:
        throw CreditNoteExceedsInvoiceError(
            creditNote.id, creditNote.amount, invoice.balanceDue
        )
```

## Exceptions

None.
