# Dashboard Valid JSON Layout

## Statement

Dashboard layout must be valid JSON configuration.

## Rationale

Invalid JSON would cause rendering failures and prevent the dashboard from displaying correctly. Validating JSON ensures the dashboard can be properly parsed and displayed.

## Scope

- Applies to: All dashboards (CON-REPORT-002)
- Bounded Context: BC-REPORT (Reporting & Analytics)
- Entities: Dashboard

## Conditions

- WHEN a dashboard is created or updated
- THEN layout MUST be valid JSON
- OTHERWISE the dashboard is rejected with error `ERR_DASHBOARD_INVALID_LAYOUT`

## Pseudocode

```
function validateDashboardLayout(dashboard):
    try:
        parsed = JSON.parse(dashboard.layout)
        if parsed == null:
            throw DashboardInvalidLayoutError(dashboard.id)
    catch JSONParseException:
        throw DashboardInvalidLayoutError(dashboard.id)
```
