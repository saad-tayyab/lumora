# Transfer Movement Creates Two Records

## Statement

A stock transfer between warehouses must create two movement records: a transfer_out from the source and a transfer_in to the destination.

## Rationale

Ensures both warehouses have accurate movement history and balances.

## Conditions

- **WHEN a transfer is executed
- THEN a transfer_out movement MUST be created at the source warehouse
- AND a transfer_in movement MUST be created at the destination warehouse
- AND both movements MUST reference the same transfer document
- OTHERWISE the transfer is rejected with error code `ERR_TRANSFER_INCOMPLETE`**

## Pseudocode

```
function executeTransfer(item, fromWarehouse, toWarehouse, quantity):
    transferDoc = createTransferDocument()
    createMovement('transfer_out', item, fromWarehouse, quantity, transferDoc)
    createMovement('transfer_in', item, toWarehouse, quantity, transferDoc)
    updateStockLevel(item, fromWarehouse, -quantity)
    updateStockLevel(item, toWarehouse, +quantity)
```

## Exceptions

None.
