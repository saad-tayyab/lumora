# Fixed Amount Discount Non-Negative

## Statement

Fixed amount discount values must be non-negative.

## Rationale

Negative fixed amounts would increase the order total instead of reducing it, which is logically invalid for a discount. Zero fixed amount is allowed (no discount).

## Scope

- Applies to: All discount policies (CON-SALES-007) with type = 'FixedAmount'
- Bounded Context: BC-SALES (Sales & Orders)
- Entities: DiscountPolicy

## Conditions

- WHEN a fixed amount discount policy is created or updated
- THEN value MUST be greater than or equal to zero
- OTHERWISE the policy is rejected with error `ERR_DISCOUNT_FIXED_AMOUNT_INVALID`

## Pseudocode

```
function validateFixedAmountDiscount(policy):
    if policy.type == 'FixedAmount':
        if policy.value < 0:
            throw DiscountFixedAmountInvalidError(policy.policy_id, policy.value)
```
