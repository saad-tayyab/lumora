# Single Active Tolerance Policy Per Tenant

## Statement

Only one reconciliation tolerance policy can be active per tenant at a time.

## Rationale

Multiple active tolerance policies would create ambiguity in reconciliation matching. A single active policy ensures consistent application of tolerance rules across all reconciliation operations within a tenant.

## Scope

- Applies to: All reconciliation tolerance policies (CON-CASH-015)
- Bounded Context: BC-CASH (Cash & Treasury)
- Entities: ReconciliationTolerancePolicy

## Conditions

- WHEN a new reconciliation tolerance policy is activated
- THEN all other tolerance policies for the same tenant MUST be deactivated
- OTHERWISE the system violates the single active policy constraint

## Pseudocode

```
function activateTolerancePolicy(newPolicy):
    // Deactivate all other policies for this tenant
    existingPolicies = findActivePoliciesByTenant(newPolicy.tenant_id)
    for policy in existingPolicies:
        policy.is_active = false
        persist(policy)
    
    newPolicy.is_active = true
    persist(newPolicy)
```

## Exceptions

- None — this rule has no exceptions.
