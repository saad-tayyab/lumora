# Posting Preserves Journal Entry Reference

## Statement

When posting journal entries to the ledger, the posting reference (account number) should be entered in the journal to indicate the entry has been posted.

## Rationale

Provides an audit trail and prevents double posting or missed posting.

## Conditions

- **WHEN** Posting a journal entry to the ledger
- **THEN** Enter the account number in the posting reference column of the journal
- **OTHERWISE** It may be unclear whether the entry has been posted
