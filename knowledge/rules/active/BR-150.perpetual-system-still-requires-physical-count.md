# Perpetual System Still Requires Physical Count

## Statement

Even with a perpetual inventory system, a physical inventory count should be taken periodically to verify the accuracy of the perpetual records.

## Rationale

Perpetual records can have errors from theft, damage, or recording mistakes. Physical counts provide verification.

## Conditions

- **WHEN** Using a perpetual inventory system
- **THEN** Periodic physical counts should be performed to verify ledger accuracy
- **OTHERWISE** Errors in perpetual records may go undetected
