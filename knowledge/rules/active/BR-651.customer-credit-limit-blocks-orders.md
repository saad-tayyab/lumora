# Customer Credit Limit Blocks Orders

## Statement

Customer orders are blocked if the credit limit is exceeded and approval is not granted.

## Rationale

Credit limits protect the business from excessive bad debt risk. Blocking orders when limits are exceeded ensures financial exposure remains within acceptable bounds while allowing for exception handling.

## Scope

- Applies to: All sales orders (CON-SALES-002)
- Bounded Context: BC-SALES (Sales & Orders)
- Entities: SalesOrder, Customer, CreditCheckPolicy

## Conditions

- WHEN a sales order is confirmed
- THEN the customer's outstanding balance plus order total MUST NOT exceed credit_limit
- OTHERWISE the order is blocked pending manager approval

## Pseudocode

```
function validateCreditLimit(order, customer, policy):
    outstandingBalance = getOutstandingBalance(customer.id)
    totalExposure = outstandingBalance + order.total
    
    if totalExposure > customer.credit_limit:
        if policy.approval_required:
            // Block order pending approval
            order.status = 'pending_approval'
            emitCreditApprovalRequired(order)
        else:
            throw CreditLimitExceededError(order.id, customer.id, totalExposure, customer.credit_limit)
```

## Exceptions

- Orders may proceed with manager approval if policy.approval_required is true.
