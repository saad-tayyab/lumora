# Receiving Report Number Uniqueness

## Statement

Receiving report numbers must be unique within a tenant.

## Rationale

Unique receiving report numbers are essential for proper identification and tracking of goods receipts. Duplicate numbers would cause confusion and make it impossible to uniquely identify specific receiving events.

## Scope

- Applies to: All receiving reports (CON-PROC-004)
- Bounded Context: BC-PROC (Procurement)
- Entities: ReceivingReport

## Conditions

- WHEN a receiving report is created
- THEN rr_number MUST be unique within the tenant
- OTHERWISE the creation is rejected with error `ERR_RR_NUMBER_NOT_UNIQUE`

## Pseudocode

```
function validateRRNumberUniqueness(rr):
    existingRR = findRRByNumber(rr.tenant_id, rr.rr_number)
    if existingRR != null AND existingRR.id != rr.id:
        throw RRNumberNotUniqueError(rr.rr_number)
```

## Exceptions

- None — this rule has no exceptions.
