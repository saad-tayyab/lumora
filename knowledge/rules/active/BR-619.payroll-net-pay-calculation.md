# Payroll Net Pay Calculation

## Statement

Total net pay must equal total gross pay minus total deductions for each payroll run.

## Rationale

This ensures accurate payroll calculations. The net pay formula is fundamental to employee compensation and must be mathematically correct to prevent underpayment or overpayment.

## Scope

- Applies to: All payroll runs (CON-HR-007)
- Bounded Context: BC-HR (Human Resources)
- Entities: Payroll

## Conditions

- WHEN a payroll run is completed
- THEN total_net_pay MUST equal total_gross_pay minus total_deductions
- OTHERWISE the payroll run is rejected with error `ERR_PAYROLL_NET_PAY_MISMATCH`

## Pseudocode

```
function validatePayrollCalculation(payroll):
    expectedNetPay = payroll.total_gross_pay - payroll.total_deductions
    
    if payroll.total_net_pay != expectedNetPay:
        throw PayrollNetPayMismatchError(payroll.id, payroll.total_net_pay, expectedNetPay)
```

## Exceptions

- None — this rule has no exceptions.
