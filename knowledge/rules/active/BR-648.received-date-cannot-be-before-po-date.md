# Received Date Cannot Be Before PO Date

## Statement

A receiving report's received date cannot be before the purchase order's order date.

## Rationale

Goods cannot be received before the order was placed. This temporal constraint ensures logical consistency of the procurement process and prevents data entry errors.

## Scope

- Applies to: All receiving reports (CON-PROC-004)
- Bounded Context: BC-PROC (Procurement)
- Entities: ReceivingReport, PurchaseOrder

## Conditions

- WHEN a receiving report is created
- THEN received_date MUST be on or after the PO's order_date
- OTHERWISE the receiving report is rejected with error `ERR_RR_DATE_BEFORE_PO_DATE`

## Pseudocode

```
function validateReceivingDate(rr):
    po = findPurchaseOrder(rr.po_id)
    if rr.received_date < po.order_date:
        throw RRDateBeforePODateError(rr.id, rr.received_date, po.order_date)
```

## Exceptions

- None — this rule has no exceptions.
