# Work in Process Inventory Assumption Rule

## Statement

When work in process inventories are estimated to be insignificant, assume zero beginning and ending work in process for budgeting purposes.

## Rationale

If WIP is immaterial, excluding it simplifies the budgeting process without materially affecting accuracy.

## Conditions

- **WHEN** WIP inventories are estimated to be insignificant
- **THEN** Set beginning and ending WIP to zero in the cost of goods manufactured calculation
- **OTHERWISE** Include actual WIP estimates in cost of goods manufactured
