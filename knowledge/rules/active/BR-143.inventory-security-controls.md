# Inventory Security Controls

## Statement

Security measures for safeguarding inventory include storing inventory in restricted areas, locking high-priced items, and using cameras, security tags, and guards.

## Rationale

Physical security measures prevent theft, damage, and unauthorized access to inventory.

## Conditions

- **WHEN** Managing physical inventory
- **THEN** Implement appropriate security measures
- **OTHERWISE** Risk of theft and damage increases
