# PO Approval Role Validation

## Statement

The system must validate the approver's role and authority against the PO amount before allowing approval.

## Rationale

Ensuring the approver has the appropriate authority for the PO amount prevents unauthorized procurement commitments. This enforces organizational hierarchy and financial controls.

## Scope

- Applies to: All purchase orders (CON-PROC-002)
- Bounded Context: BC-PROC (Procurement)
- Entities: PurchaseOrder, POApprovalPolicy

## Conditions

- WHEN a purchase order is approved
- THEN the approver's role MUST match the required authority level for the PO amount
- OTHERWISE the approval is rejected with error `ERR_PO_APPROVER_AUTHORITY_INSUFFICIENT`

## Pseudocode

```
function validateApproverAuthority(po, approver, policy):
    amount = po.total
    
    if amount <= policy.auto_approval_threshold:
        // Auto-approval or any authorized user
        return true
    else if amount <= policy.manager_threshold:
        if not approver.hasRole('manager'):
            throw POApproverAuthorityInsufficientError(po.id, approver.id, 'manager')
    else if amount <= policy.director_threshold:
        if not approver.hasRole('director'):
            throw POApproverAuthorityInsufficientError(po.id, approver.id, 'director')
    else:
        if not approver.hasRole('executive'):
            throw POApproverAuthorityInsufficientError(po.id, approver.id, 'executive')
```

## Exceptions

- None — this rule has no exceptions.
