# Suspended Customers Cannot Place Orders

## Statement

Customers with 'Suspended' status cannot place new orders.

## Rationale

Suspended customers have been flagged for payment issues, credit concerns, or other business reasons. Allowing new orders would increase exposure to an already problematic account.

## Scope

- Applies to: All sales orders (CON-SALES-002)
- Bounded Context: BC-SALES (Sales & Orders)
- Entities: SalesOrder, Customer

## Conditions

- WHEN a sales order is created
- THEN the customer's status MUST NOT be 'Suspended'
- OTHERWISE the order creation is rejected with error `ERR_CUSTOMER_SUSPENDED`

## Pseudocode

```
function validateCustomerStatus(order, customer):
    if customer.status == 'Suspended':
        throw CustomerSuspendedError(order.id, customer.id)
```

## Exceptions

- None — this rule has no exceptions.
