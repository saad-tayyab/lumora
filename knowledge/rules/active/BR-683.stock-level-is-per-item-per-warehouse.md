# Stock Level Is Per Item Per Warehouse

## Statement

There must be at most one stock level record per item per warehouse.

## Rationale

Duplicate stock levels would cause incorrect quantity tracking.

## Conditions

- **WHEN a stock level is created or queried
- THEN there MUST be at most one record for (itemId, warehouseId)
- OTHERWISE the operation is rejected with error code `ERR_STOCK_LEVEL_DUPLICATE`**

## Pseudocode

```
function upsertStockLevel(item, warehouse, quantityChange):
    existing = findStockLevel(item.id, warehouse.id)
    if existing:
        existing.quantity += quantityChange
        save(existing)
    else:
        createStockLevel(item.id, warehouse.id, quantityChange)
```

## Exceptions

None.
