# Item SKU Must Be Unique Per Tenant

## Statement

Every item must have a unique SKU within the tenant.

## Rationale

SKU is the primary identifier for inventory operations. Duplicate SKUs would cause confusion in picking, receiving, and reporting.

## Conditions

- **WHEN an item is created or updated
- THEN the SKU MUST be unique across all items in the tenant
- OTHERWISE the operation is rejected with error code `ERR_ITEM_DUPLICATE_SKU`**

## Pseudocode

```
function validateItemSKU(item):
    existing = findItemBySKU(item.sku, item.tenantId)
    if existing and existing.id != item.id:
        throw DuplicateSKUError(item.sku)
```

## Exceptions

None.
