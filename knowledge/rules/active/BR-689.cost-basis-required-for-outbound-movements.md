# Cost Basis Required For Outbound Movements

## Statement

Outbound stock movements (sale, transfer_out, return_out) must have a unit cost calculated using the item's configured costing method.

## Rationale

Outbound movements without cost would prevent accurate COGS calculation.

## Conditions

- **WHEN an outbound stock movement is created
- THEN unitCost MUST be calculated and stored
- OTHERWISE the movement is rejected with error code `ERR_MOVEMENT_NO_COST`**

## Pseudocode

```
function calculateOutboundCost(item, warehouse, quantity):
    unitCost = calculateUnitCost(item, warehouse, quantity, item.costingMethod)
    if not unitCost or unitCost <= 0:
        throw OutboundNoCostError(item.id, warehouse.id)
    return unitCost
```

## Exceptions

None.
