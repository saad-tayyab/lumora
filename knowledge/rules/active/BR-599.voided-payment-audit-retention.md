# Voided Payment Audit Retention

## Statement

Voided vendor payments must retain their complete record for audit purposes and must not be hard-deleted from the system.

## Rationale

Financial regulations require maintaining a complete audit trail of all payment transactions, including voided payments. This ensures compliance with accounting standards and supports audit investigations.

## Scope

- Applies to: All vendor payments (CON-AP-002) in voided status
- Bounded Context: BC-AP (Accounts Payable)
- Entities: VendorPayment

## Conditions

- WHEN a vendor payment status transitions to 'voided'
- THEN the payment record MUST be retained with all historical data
- OTHERWISE the system violates audit compliance requirements

## Pseudocode

```
function voidPayment(payment):
    payment.status = 'voided'
    payment.voided_at = currentTimestamp()
    payment.voided_by = currentUser()
    // Never delete the payment record
    persist(payment)
```

## Exceptions

- None — this rule has no exceptions.
