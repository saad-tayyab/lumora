# Item Must Belong to Exactly One Category

## Statement

Every item must belong to exactly one item category.

## Rationale

Items without categories cannot be properly organized or reported on.

## Conditions

- **WHEN an item is created or updated
- THEN categoryId MUST reference an existing category
- AND the item MUST belong to exactly one category
- OTHERWISE the operation is rejected with error code `ERR_ITEM_INVALID_CATEGORY`**

## Pseudocode

```
function validateItemCategory(item):
    if not item.categoryId:
        throw ItemNoCategoryError(item.id)
    category = getCategory(item.categoryId)
    if not category:
        throw CategoryNotFoundError(item.categoryId)
```

## Exceptions

None.
