# Carrying Amount Approaches Face Value at Maturity

## Statement

The carrying amount of bonds payable approaches the face value as the maturity date nears, as all discount or premium is fully amortized by maturity.

## Rationale

At maturity, the bond issuer repays the face value, so the carrying amount must equal face value at that point.

## Conditions

- **WHEN** Bonds are approaching maturity
- **THEN** Carrying amount converges to face value
- **OTHERWISE** Carrying amount equals face value plus/minus unamortized premium/discount
