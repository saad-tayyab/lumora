# Payment Application Sum Must Equal Payment Amount

## Statement

The sum of all payment applications for a payment must equal the payment amount.

## Rationale

Ensures the full payment amount is accounted for and prevents orphaned payment funds.

## Conditions

- **WHEN a payment with applications is saved
- THEN sum(applications.amountApplied) MUST equal payment.amount
- OTHERWISE the save is rejected with error code `ERR_PAYMENT_APPLICATION_MISMATCH`**

## Pseudocode

```
function validatePaymentApplications(payment):
    totalApplied = sum(app.amountApplied for app in payment.applications)
    if totalApplied != payment.amount:
        throw PaymentApplicationMismatchError(
            payment.id, totalApplied, payment.amount
        )
```

## Exceptions

Partial payments are allowed — the unapplied amount remains as a credit on the customer account.
