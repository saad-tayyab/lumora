# Debit Memorandum for Returns

## Statement

A buyer sends a debit memorandum to notify the seller of a return or to request a price allowance.

## Rationale

Provides formal documentation for the reduction in accounts payable.

## Conditions

- **WHEN** A buyer returns merchandise or requests an allowance
- **THEN** Issue a debit memorandum to the seller
- **OTHERWISE** No formal record of the return or allowance request
