# Bill Line Item Amount Calculation

## Statement

A bill line item's amount must equal the quantity multiplied by the unit price.

## Rationale

This ensures accurate calculation of line item totals on vendor bills. The amount field must be derived from quantity and unit price to prevent manual calculation errors and maintain financial accuracy.

## Scope

- Applies to: All bill line items (CON-AP-004)
- Bounded Context: BC-AP (Accounts Payable)
- Entities: BillLineItem

## Conditions

- WHEN a bill line item is created or updated
- THEN amount MUST equal quantity multiplied by unit_price
- OTHERWISE the line item is rejected with error `ERR_LINE_ITEM_AMOUNT_INVALID`

## Pseudocode

```
function calculateLineItemAmount(lineItem):
    expectedAmount = lineItem.quantity * lineItem.unit_price
    
    if lineItem.amount != expectedAmount:
        throw LineItemAmountError(lineItem.id, lineItem.amount, expectedAmount)
```

## Exceptions

- None — this rule has no exceptions.
