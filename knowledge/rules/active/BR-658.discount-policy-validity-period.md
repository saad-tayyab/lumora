# Discount Policy Validity Period

## Statement

A discount policy's valid_until date must be after valid_from when specified.

## Rationale

A discount policy cannot expire before it starts. This temporal constraint ensures logical consistency of discount validity periods.

## Scope

- Applies to: All discount policies (CON-SALES-007)
- Bounded Context: BC-SALES (Sales & Orders)
- Entities: DiscountPolicy

## Conditions

- WHEN a discount policy is created or updated with valid_until specified
- THEN valid_until MUST be after valid_from
- OTHERWISE the policy is rejected with error `ERR_DISCOUNT_VALIDITY_INVALID`

## Pseudocode

```
function validateDiscountValidity(policy):
    if policy.valid_until != null:
        if policy.valid_until <= policy.valid_from:
            throw DiscountValidityInvalidError(policy.policy_id, policy.valid_from, policy.valid_until)
```

## Exceptions

- None — this rule has no exceptions.
