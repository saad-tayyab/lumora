# Horizontal Analysis Rule

## Statement

When performing horizontal analysis, compute both the dollar amount of change and the percentage change from the base period to assess trends.

## Rationale

Both absolute and relative changes are needed to fully understand financial trends.

## Conditions

- **WHEN** Comparing financial statement items across periods
- **THEN** Calculate dollar change and percentage change using a base year
- **OTHERWISE** Trend analysis may miss significant changes hidden in absolute numbers
