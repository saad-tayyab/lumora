# Inventory Costing Method Consistency

## Statement

Once an inventory costing method is selected, it should be used consistently from period to period to ensure comparability of financial statements.

## Rationale

Consistency in accounting methods is required by GAAP to allow meaningful comparison of financial results across periods.

## Conditions

- **WHEN** Selecting an inventory costing method
- **THEN** Use the same method consistently in future periods
- **OTHERWISE** Financial statements would not be comparable across periods
