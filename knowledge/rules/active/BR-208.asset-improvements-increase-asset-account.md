# Asset Improvements Increase Asset Account

## Statement

Costs incurred to improve a fixed asset's service value are capital expenditures recorded as increases to the asset account.

## Rationale

Improvements add new service capacity beyond original specifications.

## Conditions

- **WHEN** A cost adds new service value to the asset
- **THEN** Debit the Fixed Asset account
- **OTHERWISE** If it only maintains, treat as revenue expenditure
