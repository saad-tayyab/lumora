# Appropriate Allocation Base Selection

## Statement

The allocation base used for overhead or selling/admin expense allocation should reflect the actual cause of the cost. Using an inappropriate base (like sales dollars for all expenses) can distort product costs.

## Rationale

Costs should be allocated based on what actually drives them, not on convenient but unrelated measures.

## Conditions

- **WHEN** Selecting an allocation base for indirect costs
- **THEN** Choose a base that has a cause-and-effect relationship with the costs being allocated
- **OTHERWISE** Product costs will be distorted and profitability analysis will be misleading
