# Manufacturing Overhead Variance Decomposition Rule

## Statement

Total manufacturing overhead variance is decomposed into a controllable variance (variable overhead) and a volume variance (fixed overhead) because overhead has both fixed and variable cost elements.

## Rationale

Fixed and variable overhead have different cost behaviors and require different analysis approaches. Variable overhead is controlled through spending; fixed overhead variance relates to production volume.

## Conditions

- **WHEN** Analyzing manufacturing overhead variances
- **THEN** Separate into controllable variance (variable overhead) and volume variance (fixed overhead)
- **OTHERWISE** The different cost behaviors of fixed and variable overhead would be conflated
