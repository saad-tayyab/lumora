# Payroll Check Sequential Numbering

## Statement

Payroll checks must be issued in sequential order, and the next check number must be tracked.

## Rationale

Sequential numbering provides an internal control mechanism to detect missing or unauthorized checks.

## Conditions

- **WHEN** A payroll is processed
- **THEN** Checks are numbered sequentially and the next available number is recorded
- **OTHERWISE** Internal control weakness
