# Invoice Due Date Must Be After Issue Date

## Statement

The invoice due date must be after the issue date.

## Rationale

A due date before the issue date would create an immediately overdue invoice.

## Conditions

- **WHEN an invoice is created or updated
- THEN dueDate MUST be > issueDate
- OTHERWISE the change is rejected with error code `ERR_INVOICE_DUE_DATE_INVALID`**

## Pseudocode

```
function validateDueDate(invoice):
    if invoice.dueDate <= invoice.issueDate:
        throw InvalidDueDateError(invoice.id, invoice.dueDate, invoice.issueDate)
```

## Exceptions

None.
