# Depreciation Methods Can Differ by Asset Class

## Statement

A company may use different depreciation methods for different classes of fixed assets, and may use different methods for financial statements versus tax purposes.

## Rationale

Different asset classes may have different usage patterns; tax rules (MACRS) differ from GAAP.

## Conditions

- **WHEN** Computing depreciation for various asset classes
- **THEN** May use different methods for each class as appropriate
- **OTHERWISE** Consistency within each asset class is required
