# Present Value Index Ranking Rule

## Statement

When capital investment funds are limited, proposals should be ranked by their present value index; a higher index indicates a more desirable investment per dollar invested.

## Rationale

The PV index provides a relative measure that allows comparison of proposals with different investment amounts, optimizing the return per dollar invested.

## Conditions

- **WHEN** Capital funds are limited and proposals involve different investment amounts
- **THEN** Rank proposals by PV index (highest first); fund proposals in order of ranking until funds are exhausted
- **OTHERWISE** Use NPV alone to rank proposals
