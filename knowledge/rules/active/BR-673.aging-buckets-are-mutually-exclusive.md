# Aging Buckets Are Mutually Exclusive

## Statement

Aging bucket boundaries must not overlap, and every invoice must fall into exactly one bucket.

## Rationale

Overlapping buckets would cause double-counting in aging reports.

## Conditions

- **WHEN aging buckets are configured
- THEN each bucket range MUST be non-overlapping and contiguous
- AND every invoice MUST be assignable to exactly one bucket
- OTHERWISE the configuration is rejected with error code `ERR_AGING_BUCKETS_INVALID`**

## Pseudocode

```
function validateAgingBuckets(buckets):
    sorted = sort(buckets, by: 'lowerBound')
    for i in range(1, len(sorted)):
        if sorted[i].lowerBound <= sorted[i-1].upperBound:
            throw OverlappingBucketsError(sorted[i-1].id, sorted[i].id)
```

## Exceptions

None.
