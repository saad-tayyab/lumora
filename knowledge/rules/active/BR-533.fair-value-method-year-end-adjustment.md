# Fair Value Method - Year-End Adjustment

## Statement

At each reporting date, adjust the equity investment portfolio to fair value. Report unrealized gains and losses on the income statement for trading securities, and in other comprehensive income for available-for-sale securities.

## Rationale

Fair value reporting provides more relevant information about the current value of investments.

## Conditions

- **WHEN** Reporting date arrives for equity investments
- **THEN** Compare total fair value to total cost; record unrealized gain or loss in the appropriate account
- **OTHERWISE** N/A
