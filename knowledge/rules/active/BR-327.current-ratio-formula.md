# Current Ratio Formula

## Statement

The current ratio is computed as current assets divided by current liabilities.

## Rationale

The current ratio provides a relative measure of the ability to pay current liabilities, which is more useful than working capital alone for comparing companies of different sizes.

## Conditions

- **WHEN** Evaluating a company's current position
- **THEN** Current ratio = Current assets / Current liabilities
- **OTHERWISE** The relative measure of short-term liquidity is unknown
