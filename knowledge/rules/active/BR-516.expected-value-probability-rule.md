# Expected Value Probability Rule

## Statement

Expected value analysis incorporates uncertainty by computing a probability-weighted average of possible outcomes; the resulting expected NPV should be positive for the investment to be justified.

## Rationale

Probabilities reflect management's assessment of the likelihood of various scenarios, providing a more realistic basis for decision-making than single-point estimates.

## Conditions

- **WHEN** Multiple possible outcomes exist for key inputs (e.g., cash flows) with assigned probabilities
- **THEN** Expected Value = Σ (Outcome × Probability); use expected value as the input for NPV computation; accept if expected NPV > 0
- **OTHERWISE** Use single-point estimates
