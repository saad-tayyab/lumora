# Salary Base Amount Non-Negative

## Statement

An employee's base salary amount must be non-negative.

## Rationale

Negative salary amounts are logically invalid and would create errors in payroll calculations. Zero salary is allowed for unpaid positions or volunteer roles.

## Scope

- Applies to: All salary records (CON-HR-009)
- Bounded Context: BC-HR (Human Resources)
- Entities: Salary

## Conditions

- WHEN a salary record is created or updated
- THEN base_amount MUST be greater than or equal to zero
- OTHERWISE the salary record is rejected with error `ERR_SALARY_BASE_AMOUNT_INVALID`

## Pseudocode

```
function validateSalaryAmount(salary):
    if salary.base_amount < 0:
        throw SalaryBaseAmountInvalidError(salary.employee_id, salary.base_amount)
```

## Exceptions

- None — this rule has no exceptions.
