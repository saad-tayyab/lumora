# LLC Liquidation Uses Member Equity Titles

## Statement

The liquidation process for an LLC is identical to a partnership except that account titles use 'Member Equity' instead of 'Capital'.

## Rationale

LLCs follow the same liquidation principles as partnerships, with only terminology differences.

## Conditions

- **WHEN** An LLC is being liquidated
- **THEN** Use 'Member Equity' account titles in the liquidation statement
- **OTHERWISE** Account titles would not reflect the LLC structure
