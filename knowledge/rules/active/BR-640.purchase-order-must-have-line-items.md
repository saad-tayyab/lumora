# Purchase Order Must Have Line Items

## Statement

A purchase order must have at least one line item to be submitted.

## Rationale

A purchase order without line items has no items to procure. Requiring at least one line item ensures the PO is meaningful and can be properly processed through the procurement workflow.

## Scope

- Applies to: All purchase orders (CON-PROC-002)
- Bounded Context: BC-PROC (Procurement)
- Entities: PurchaseOrder, POLineItem

## Conditions

- WHEN a purchase order is submitted
- THEN it MUST contain at least one line item
- OTHERWISE the submission is rejected with error `ERR_PO_NO_LINE_ITEMS`

## Pseudocode

```
function submitPurchaseOrder(po):
    if po.lineItems == null OR po.lineItems.isEmpty():
        throw PONoLineItemsError(po.id)
```
