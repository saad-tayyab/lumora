# Assign Costs to Ending WIP

## Statement

Ending work in process inventory is valued by multiplying the ending WIP equivalent units by the cost per equivalent unit for each cost category (materials and conversion).

## Rationale

Values partially completed units at the cost incurred in the current period.

## Conditions

- **WHEN** Ending WIP exists at period end
- **THEN** Ending WIP cost = Equivalent units x Cost per equivalent unit for each category
- **OTHERWISE** No ending inventory to value
