# Suspended Vendors Cannot Receive Orders

## Statement

Vendors with 'suspended' status cannot receive new purchase orders.

## Rationale

Suspended vendors have been flagged for quality, compliance, or performance issues. Issuing new orders to suspended vendors would bypass established controls and expose the organization to risk.

## Scope

- Applies to: All purchase orders (CON-PROC-002)
- Bounded Context: BC-PROC (Procurement)
- Entities: PurchaseOrder, Vendor

## Conditions

- WHEN a purchase order is created for a vendor
- THEN the vendor's status MUST NOT be 'suspended'
- OTHERWISE the purchase order is rejected with error `ERR_VENDOR_SUSPENDED`

## Pseudocode

```
function validateVendorStatus(po, vendor):
    if vendor.status == 'suspended':
        throw VendorSuspendedError(po.id, vendor.id)
```

## Exceptions

- None — this rule has no exceptions.
