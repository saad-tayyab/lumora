# Depreciation Calculated Monthly

## Statement

Depreciation is calculated and posted on a monthly basis, with entries generated at month-end.

## Rationale

Monthly depreciation posting ensures financial statements reflect the systematic allocation of asset cost over time in a consistent and timely manner. Aligns with standard accounting practices and period-end closing processes.

## Scope

- Applies to: All depreciable fixed assets (BC-ASSET)
- Bounded Context: BC-ASSET (Fixed Asset Management)
- Entities: FixedAsset, DepreciationEntry, AccountingPeriod

## Conditions

- **WHEN** the monthly depreciation run is executed at month-end
- **THEN** depreciation must be calculated for all active depreciable assets
- **AND** entries must be posted to the current open accounting period
- **OTHERWISE** the depreciation run must report the failed assets

## Pseudocode

```
function runMonthlyDepreciation(periodId):
    assets = findActiveDepreciableAssets()
    period = findAccountingPeriod(periodId)
    
    for asset in assets:
        monthlyDepreciation = calculateMonthlyDepreciation(asset, period)
        entry = createDepreciationEntry(asset, monthlyDepreciation, period)
        postEntry(entry)
```

## Exceptions

- Assets placed in service mid-month receive a partial month depreciation based on the number of days held.
- Assets fully depreciated during the period receive depreciation only up to the point of full depreciation.
