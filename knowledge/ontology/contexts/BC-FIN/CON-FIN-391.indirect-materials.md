# Indirect Materials

## Definition

Materials used in production that are either not an integral part of the finished product or not conveniently traceable to it, such as factory supplies and lubricants.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| classification | string | Part of manufacturing overhead |
| examples | string | Lubricants, cleaning supplies, small tools |
