# Direct Materials

## Definition

Materials that are an integral part of the manufactured end product and whose costs can be conveniently traced to the finished product.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| traceability | string | Directly traceable to the product |
| materiality | string | Integral part of the finished product |
