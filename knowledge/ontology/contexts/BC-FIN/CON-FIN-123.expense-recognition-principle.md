# Expense Recognition Principle

## Definition

The accounting principle that expenses are recorded in the same period as the related revenues they help generate, also known as the matching principle.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| matching_basis | string | Expenses matched to related revenues |
| timing | string | When expense is recognized in the accounting records |
