# Double-Entry Accounting System

## Definition

A system of accounting in which every transaction affects at least two accounts. Total debits must always equal total credits.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| rule | string | Every transaction affects at least two accounts |
| balance | string | Total debits must equal total credits |
