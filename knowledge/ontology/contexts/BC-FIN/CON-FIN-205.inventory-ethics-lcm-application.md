# Inventory Ethics - LCM Application

## Definition

The ethical obligation to apply the lower-of-cost-or-market method when inventory market value declines below cost, even when doing so reduces reported earnings. Failure to apply LCM misrepresents financial position.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| trigger | string | Market value of inventory falls below cost |
| ethical_requirement | string | Accountant must recommend and apply LCM regardless of earnings pressure |
| consequence_of_non_compliance | string | Misleading financial statements, potential fraud, harm to investors and creditors |
