# Capital Investment Analysis

## Definition

The process by which management plans, evaluates, and controls investments in fixed assets, also called capital budgeting.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| investment_type | string | Fixed assets such as property, plant, and equipment |
| evaluation_horizon | integer | Number of years the investment affects operations |
| required_rate_of_return | decimal | Minimum rate of return required by management |
