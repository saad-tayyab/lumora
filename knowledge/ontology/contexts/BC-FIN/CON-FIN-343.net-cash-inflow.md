# Net Cash Inflow

## Definition

Cash revenues minus cash expenses (excluding non-cash items like depreciation) for a period, representing the actual cash generated by an investment.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| cash_revenues | decimal | Cash received from operations |
| cash_expenses | decimal | Cash paid for expenses excluding depreciation |
| net_cash_inflow | decimal | Cash revenues minus cash expenses |
