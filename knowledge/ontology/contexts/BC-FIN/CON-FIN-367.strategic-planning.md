# Strategic Planning

## Definition

The management process of developing long-term objectives, typically with a time horizon of five to ten years.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| time_horizon | string | Long-term (5-10 years) |
| purpose | string | Set long-term direction and objectives |
| example | string | Increasing market share through new products or market expansion |
