# Residual Value

## Definition

The estimated value of a fixed asset at the end of its useful life. Also referred to as scrap value, salvage value, or trade-in value.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| estimated_amount | decimal | The estimated value at end of useful life |
