# Standard Costing

## Definition

A costing method that assigns direct materials, direct labor, and manufacturing overhead using predetermined standard costs.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| direct_costs | string | Standard costs for DM and DL |
| overhead | string | Standard overhead rates |
