# Monitoring

## Definition

The process of observing employee behavior and the accounting system for indicators of control problems. One of the five elements of internal control. Used to locate weaknesses and improve controls.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| internal_auditors | string | Independent employees who evaluate controls daily |
| external_auditors | string | Evaluate and report on internal control as part of annual financial statement audit |
| warning_signs | string | Abrupt lifestyle changes, close supplier relationships, refusal to take vacations, missing documentation |
