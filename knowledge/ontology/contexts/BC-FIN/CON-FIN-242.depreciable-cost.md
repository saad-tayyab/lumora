# Depreciable Cost

## Definition

The difference between a fixed asset's initial cost and its residual value. This is the cost that is allocated over the asset's useful life as depreciation expense.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| amount | decimal | Initial cost minus residual value |
