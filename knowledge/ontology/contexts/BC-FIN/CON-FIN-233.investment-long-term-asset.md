# Investment (Long-Term Asset)

## Definition

A long-lived asset not used in normal operations and held for future resale or income generation. Reported separately from fixed assets on the balance sheet.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| asset_type | String | Undeveloped land, securities, etc. |
| purpose | String | Held for future resale or income, not for operations |
