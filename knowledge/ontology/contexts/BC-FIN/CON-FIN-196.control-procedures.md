# Control Procedures

## Definition

Procedures that provide reasonable assurance that business goals will be achieved, including prevention of fraud. One of the five elements of internal control. Includes competent personnel, separating responsibilities, and proofs and security measures.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| competent_personnel | string | Proper training, supervision, duty rotation, and mandatory vacations |
| separation_of_duties | string | Divide responsibilities for related operations among two or more people |
| proofs_and_security | string | Authorization, approval, reconciliation, and physical safeguards |
