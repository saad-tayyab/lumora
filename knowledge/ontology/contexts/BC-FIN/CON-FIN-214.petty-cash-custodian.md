# Petty Cash Custodian

## Definition

The employee responsible for disbursing monies from the petty cash fund and maintaining petty cash receipts for each disbursement.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| responsibilities | string | Disburse funds, record receipts, safeguard cash |
| restrictions | string | May be limited on maximum amount and types of payments |
| documentation | string | Records details on petty cash receipts form |
