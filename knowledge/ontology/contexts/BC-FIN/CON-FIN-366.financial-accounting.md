# Financial Accounting

## Definition

The process of preparing general-purpose financial statements (income statement, balance sheet, statement of stockholders' equity, statement of cash flows) according to GAAP for external users.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| primary_users | string | External users: shareholders, creditors, government agencies, general public |
| guidelines | string | Prepared according to GAAP |
| reporting_frequency | string | Fixed intervals (monthly, quarterly, yearly) |
| focus | string | Company as a whole |
