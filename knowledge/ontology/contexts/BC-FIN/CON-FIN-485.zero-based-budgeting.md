# Zero-Based Budgeting

## Definition

A budgeting approach that requires managers to estimate sales, production, and other operating data as though operations are being started for the first time, rather than adjusting prior-year figures.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| approach | string | Start from zero and justify all expenses each period |
| benefit | string | Provides a fresh view of operations each year, avoiding legacy inefficiencies |
