# Budget Gaming

## Definition

The tendency for managers to manipulate budget estimates for personal advantage, such as padding budgets with excess resources, understating sales potential, or spending unnecessarily to avoid losing budget allocations.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| padding | string | Inflating budget requests to create a cushion for unexpected events |
| sandbagging | string | Understating sales potential to make quotas easier to achieve |
| land_grabbing | string | Overstaining sales potential to secure more resources |
| spend_it_or_lose_it | string | Wasteful spending to avoid losing unspent budget allocations |
