# Lean Manufacturing

## Definition

A production philosophy focused on minimizing waste and inventory levels. Key features include pull manufacturing (production matches demand), production cells, and just-in-time inventory management.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| pull_manufacturing | boolean | Products manufactured only as ordered by customers |
| inventory_minimization | boolean | Goal of reducing inventory levels to minimum necessary |
| production_cells | boolean | Centralized work locations for efficient production |
