# Evaluation

## Definition

The management process by which management monitors operations by comparing actual and expected results. Provides feedback for performance evaluation, promotions, and compensation.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| purpose | string | Monitor operations and provide feedback |
| philosophy | string | Management by exception - focusing on unexpected good or bad performance |
