# Pro Forma Financial Statements

## Definition

Projected or forecasted financial statements that present expected future financial position and results based on assumed conditions and management plans.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| projection_type | String | Nature of the projections (budget, forecast, scenario) |
| time_horizon | String | Future period(s) covered by the projections |
