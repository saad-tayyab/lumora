# Complicating Factor — Sustainability

## Definition

Capital investments in sustainability (e.g., solar panels, water recycling) can be evaluated using standard NPV methods when savings are quantifiable, or qualitatively when impacts are not easily measured in dollar terms.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| investment_type | string | Sustainability-related investment (energy, environment, employee wellness) |
| quantifiable_savings | decimal | Annual cost savings that can be estimated |
| qualitative_benefits | array | Non-monetary benefits (morale, reputation, environmental impact) |
