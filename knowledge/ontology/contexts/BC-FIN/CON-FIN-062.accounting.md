# Accounting

## Definition

The process of identifying, measuring, recording, and communicating economic events of an organization to interested users for decision-making.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| identification | process | Selecting economic events relevant to the business |
| measurement | process | Quantifying events in monetary terms |
| recording | process | Keeping a chronological diary of events in a systematic manner |
| communication | process | Preparing accounting reports and analyzing/interpreting them |
