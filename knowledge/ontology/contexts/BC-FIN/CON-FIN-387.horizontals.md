# Horizontals

## Definition

Departments within a company that provide services to verticals and other horizontals, such as Marketing, Human Resources, IT, Legal, Facilities, Accounting, and Finance.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| purpose | string | Provide services to verticals and other horizontals |
| examples | string | Marketing, HR, IT, Legal, Facilities, Accounting, Finance |
| reporting | string | Do not report P&L statements |
