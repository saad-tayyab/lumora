# Personal Investment Analysis

## Definition

The application of capital investment techniques to personal financial decisions, such as evaluating the return on educational investments by comparing present values of differential cash flows.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| investment_cost | decimal | Cost of the personal investment (e.g., tuition) |
| incremental_income | decimal | Additional income generated by the investment |
| time_horizon | integer | Number of years over which benefits are received |
