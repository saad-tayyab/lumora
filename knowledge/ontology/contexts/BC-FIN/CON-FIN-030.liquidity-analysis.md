# Liquidity Analysis

## Definition

Analysis that evaluates the ability of a company to convert current assets into cash. Banks and short-term creditors rely heavily on this analysis.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| focus | string | Current assets, current liabilities, receivables, and inventory |
| users | string | Banks and short-term creditors |
