# Hybrid Costing

## Definition

A cost system combining elements of both job order and process costing. Also called operations costing. Used for products that are unique from one another but share common components.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| unit_of_tracking | string | Combination of job and process tracking |
| typical_users | string | Companies with unique products sharing common components |
