# Statement of Stockholders' Equity

## Definition

A financial statement that reports changes in all stockholders' equity accounts for a period, including paid-in capital, retained earnings, and treasury stock.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| period | DateRange | Reporting period covered |
| columns | list | One column per equity account |
