# Eco-Efficiency Measures

## Definition

Sustainability metrics that help managers evaluate savings generated by using fewer natural resources in operations.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| energy_efficiency | string | Energy cost savings from replacing lighting with energy-efficient alternatives |
| material_use_efficiency | string | Materials cost savings from reducing product packaging |
| fuel_efficiency | string | Fuel cost savings from replacing gas-powered vehicles with hybrid/alternative energy vehicles |
| waste_efficiency | string | Waste removal cost savings from recycling and reusing waste and by-product materials |
