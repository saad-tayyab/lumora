# Lessor

## Definition

The party who owns the asset in a lease contract and grants the right to use it to the lessee.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| entity_name | String | Name of the lessor |
| asset_owned | String | The asset being leased |
