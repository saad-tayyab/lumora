# Theory of Constraints

## Definition

A manufacturing strategy that focuses on reducing the influence of bottlenecks on production processes to maximize overall profitability.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| focus | string | Focuses on identifying and managing the most limiting constraint |
| objective | string | Maximize throughput given the bottleneck constraint |
