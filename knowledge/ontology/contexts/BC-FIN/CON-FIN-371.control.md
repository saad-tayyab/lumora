# Control

## Definition

The management process by which management takes actions to encourage specific behaviors or outcomes, providing information and guidance for day-to-day operations.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| purpose | string | Guide employee and manager actions |
| methods | string | Communicating plans, measurements, and evaluations to supervisors and employees |
