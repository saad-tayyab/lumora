# Operational Planning

## Definition

The process of developing short-term objectives and actions to achieve strategic objectives.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| time_horizon | string | Short-term (annual) |
| purpose | string | Translate strategic objectives into actionable plans |
| example | string | Increasing annual R&D spending to develop new products |
