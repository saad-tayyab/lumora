# Accounting Equation Solving

## Definition

The ability to solve for any unknown element in the accounting equation (Assets = Liabilities + Owner's Equity) when two of the three elements are known.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| assets | money | Total resources owned |
| liabilities | money | Total debts owed |
| owner_equity | money | Owner's claim on assets |
