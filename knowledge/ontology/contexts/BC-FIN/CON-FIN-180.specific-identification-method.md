# Specific Identification Method

## Definition

An inventory costing method where the unit sold is identified with a specific purchase. Used when each inventory unit can be separately identified, such as automobiles with unique serial numbers.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| identification_basis | string | Each unit is uniquely identifiable |
