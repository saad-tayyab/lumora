# Private Accounting

## Definition

Accounting work performed for a single business entity (as opposed to public accounting which serves multiple clients). Includes roles such as staff accountant, cost accountant, tax accountant, and internal auditor.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| employer | String | The single business entity served |
| scope | String | Internal accounting functions for one organization |
