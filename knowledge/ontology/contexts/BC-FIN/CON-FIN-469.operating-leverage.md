# Operating Leverage

## Definition

A measure of how sensitive operating income is to a percentage change in sales. High operating leverage means a small percentage change in sales results in a large percentage change in operating income.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| formula | string | Contribution Margin / Operating Income |
| interpretation | string | Higher leverage = greater sensitivity to sales changes |
