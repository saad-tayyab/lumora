# Dynamic Pricing

## Definition

A pricing strategy where prices are adjusted in real-time based on market conditions, demand, supply, competitor pricing, and other factors.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| price_adjustment_trigger | String | Factors that trigger price changes |
| update_frequency | String | How often prices are recalculated |
