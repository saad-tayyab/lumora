# Common-Sized Statement

## Definition

A financial statement in which all items are expressed as percentages with no dollar amounts, useful for comparing one company with another or comparing a company with industry averages.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| items | array | All financial statement line items expressed as percentages |
