# Qualitative Investment Factors

## Definition

Non-financial considerations in capital investment decisions that cannot be easily quantified, such as strategic positioning, competitive advantage, technology leadership, and market uncertainty.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| strategic_importance | string | Alignment with long-term strategy |
| uncertainty_level | string | Degree of uncertainty in projections |
| competitive_necessity | string | Whether the investment is required to remain competitive |
