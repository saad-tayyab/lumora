# Measurement

## Definition

The management process where managers develop and agree upon performance metrics on how well the company is achieving its objectives.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| purpose | string | Track progress toward objectives |
| examples | string | Market share, customer satisfaction, workforce diversity, earnings per share |
