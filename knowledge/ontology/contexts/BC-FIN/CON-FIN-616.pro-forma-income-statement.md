# Pro Forma Income Statement

## Definition

A projected income statement that shows expected revenues, expenses, and net income for a future period based on management's plans and assumptions.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| projected_period | String | The future period covered |
| revenue_assumptions | String | Assumptions about future revenue |
| expense_assumptions | String | Assumptions about future expenses |
