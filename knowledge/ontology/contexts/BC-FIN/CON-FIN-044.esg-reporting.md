# ESG Reporting

## Definition

Environmental, Social, and Governance reporting that discloses a company's impact on the environment and society, and governance practices.

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| environmental | string | Environmental impact and sustainability |
| social | string | Social impact and community relations |
| governance | string | Corporate governance practices |
