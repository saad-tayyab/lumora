# Inventory Control

## Definition

The process of safeguarding inventory from damage or theft and ensuring accurate reporting in the financial statements. Controls begin when inventory is ordered and include document matching, perpetual records, and security measures.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| objectives | string | Safeguarding inventory and accurate financial reporting |
| documents_used | string | Purchase order, receiving report, vendor's invoice |
