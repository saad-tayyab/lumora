# Cost System

## Definition

A system that measures, records, and reports product costs for setting prices, controlling operations, and developing financial statements.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| purpose | string | Measure, record, and report product costs |
| users | string | Managers for pricing, control, and financial reporting |
