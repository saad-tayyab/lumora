# Liquidity

## Definition

The ability of a business to convert its assets into cash quickly and without significant loss of value.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| asset_type | string | The type of asset being evaluated |
| conversion_speed | string | How quickly the asset can be converted to cash |
