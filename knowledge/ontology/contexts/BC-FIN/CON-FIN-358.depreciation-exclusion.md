# Depreciation Exclusion

## Definition

Depreciation expense is not reported under the direct method because it does not involve a cash outflow. It is only relevant in the indirect method as an add-back to net income.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| reason | string | Depreciation is a noncash expense |
