# Incremental Budgeting

## Definition

A budgeting approach that starts with last year's actual results and adjusts for expected changes in the coming year. More common than zero-based budgeting.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| approach | string | Revise prior year budget based on actual results and expected changes |
| drawback | string | May perpetuate past inefficiencies and lacks fresh perspective |
