# Budget Committee

## Definition

A group responsible for developing and overseeing the budget process, typically consisting of the budget director, controller, treasurer, production manager, and sales manager.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| members | array | Budget director, controller, treasurer, production manager, sales manager |
| responsibility | string | Develop budget estimates, monitor budget process, resolve disputes |
