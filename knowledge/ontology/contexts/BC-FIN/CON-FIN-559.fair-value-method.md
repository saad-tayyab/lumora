# Fair Value Method

## Definition

An accounting method for equity investments of less than 20% ownership where investments are recorded at cost initially and adjusted to fair value at each reporting date. Unrealized gains/losses are reported on the income statement.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| initial_recording | string | Recorded at cost |
| fair_value_adjustment | string | Adjusted to fair value at reporting date |
| unrealized_gains_losses | string | Reported on income statement |
