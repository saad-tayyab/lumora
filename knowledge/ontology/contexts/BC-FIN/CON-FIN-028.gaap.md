# GAAP

## Definition

Generally Accepted Accounting Principles, the framework of accounting standards, rules, and procedures that govern financial reporting in the United States.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| authority | string | Standard-setting body (FASB) |
| scope | string | Applies to all US companies reporting publicly |
