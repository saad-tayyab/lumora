# Cost Principle

## Definition

Accounting information is based on actual cost. The cost is measured on a cash or cash equivalent basis and includes all expenditures necessary to acquire an asset and make it ready for its intended use.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| basis | string | Cash or cash equivalent basis |
| scope | string | Includes all expenditures to acquire and prepare the asset |
