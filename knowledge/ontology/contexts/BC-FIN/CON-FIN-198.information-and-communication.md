# Information and Communication

## Definition

An essential element of internal control that involves gathering and sharing information about the control environment, risk assessment, control procedures, and monitoring. One of the five elements of internal control.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| internal_information | string | Information used by management for guiding operations and compliance |
| external_information | string | External pronouncements (e.g., FASB standards) used to assess impact on financial statements |
| communication_channels | string | Vertical and horizontal communication across the organization |
