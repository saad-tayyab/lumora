# Managerial Accounting

## Definition

The process of developing information and management tools to achieve an organization's objectives. Also called management accounting, it supports strategic planning, measurement, evaluation, and control.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| primary_users | string | Company management (internal users) |
| purpose | string | Develop costing information and management tools for decision-making |
| reporting_frequency | string | As-needed basis, not limited to fixed intervals |
