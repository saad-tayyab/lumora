# Special-Purpose Funds

## Definition

Cash funds established for specific needs such as payroll or travel expenses. Similar to petty cash funds in how they are established and controlled.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| examples | string | Payroll fund, travel fund |
| establishment | string | Established by cashing a check for the amount needed |
| replenishment | string | Periodically replenished based on expense reports |
