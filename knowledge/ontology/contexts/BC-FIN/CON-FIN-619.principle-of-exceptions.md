# Principle of Exceptions

## Definition

A management principle stating that managers should focus their attention on areas that deviate significantly from expected results (variances), rather than reviewing all areas equally.

## Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| id | UUID v7 | Unique identifier |
| focus_area | String | Areas with significant variances from budget or standard |
| action_trigger | String | Threshold that determines when a variance requires management attention |
