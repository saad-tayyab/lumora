# UserCredential belongs-to User

## Definition

One-to-one relationship from UserCredential to User. Each credential record is associated with exactly one user.

## Source

- **CON-AUTH-006** (UserCredential) — Entity
- **CON-AUTH-001** (User) — Aggregate root

## Constraints

- Password hashes must never be stored in plain text.
- Credential must comply with PasswordPolicy (CON-AUTH-016).

## Bidirectional

- **Credential → User:** A credential belongs to one user
- **User → Credential:** A user has one credential (REL-004)
