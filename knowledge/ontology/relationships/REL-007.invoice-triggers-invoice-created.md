# Invoice triggers InvoiceCreated

## Definition

When an invoice is successfully created and persisted, an InvoiceCreated event is emitted. This event is used for cross-context communication to BC-FIN and BC-REPORT.

## Source

- **CON-AR-002** (Invoice) — Aggregate root
- **CON-AR-009** (InvoiceCreated) — Domain event

## Constraints

- The event must be emitted atomically with the invoice creation.
- INV-CROSS-002: Cross-context communication happens through domain events only.
