# CreditNote triggers CreditNoteIssued

## Definition

When a credit note is successfully issued and persisted, a CreditNoteIssued event is emitted. This event is used for cross-context communication to BC-FIN and BC-REPORT.

## Source

- **CON-AR-006** (CreditNote) — Entity
- **CON-AR-011** (CreditNoteIssued) — Domain event

## Constraints

- The event must be emitted atomically with the credit note issuance.
- INV-CROSS-002: Cross-context communication happens through domain events only.
