# BillPaid triggers BC-FIN

## Description

When a BillPaid event is emitted, it triggers the creation of journal entries in the Financial Management bounded context to reduce accounts payable and record cash outflow.

## Source

- CON-AP-009 (BillPaid) — event

## Target

- BC-FIN (Financial Management) — journal entry

## Notes

- Cross-context communication happens through domain events only (INV-CROSS-002).
- The BC-FIN context consumes the event and posts the payment entry.
- No direct table access across bounded contexts (INV-CROSS-001).
