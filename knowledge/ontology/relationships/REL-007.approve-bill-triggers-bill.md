# ApproveBill targets Bill

## Description

The ApproveBill command targets a specific bill and transitions it to approved status if the approval workflow conditions are met.

## Source

- CON-AP-011 (ApproveBill) — command

## Target

- CON-AP-003 (Bill) — aggregate

## Notes

- Bill must be in pending_approval status.
- Three-way match must pass for PO-linked bills.
