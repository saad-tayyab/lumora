# User has-many OAuthProviders

## Definition

One-to-many relationship between users and OAuth provider links. A user can authenticate via multiple external identity providers (Google, GitHub, Microsoft).

## Source

- **CON-AUTH-001** (User) — Aggregate root
- **CON-AUTH-005** (OAuthProvider) — Entity

## Constraints

- A user can only have one link per provider type.
- OAuth tokens must be encrypted at rest.

## Bidirectional

- **User → OAuthProviders:** A user has many linked providers
- **OAuthProvider → User:** A provider link belongs to one user
