# Payment triggers PaymentReceived

## Definition

When a payment is successfully recorded and persisted, a PaymentReceived event is emitted. This event is used for cross-context communication to BC-FIN and BC-CASH.

## Source

- **CON-AR-004** (Payment) — Aggregate root
- **CON-AR-010** (PaymentReceived) — Domain event

## Constraints

- The event must be emitted atomically with the payment recording.
- INV-CROSS-002: Cross-context communication happens through domain events only.
