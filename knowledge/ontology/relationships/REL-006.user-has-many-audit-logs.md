# User has-many AuditLogs

## Definition

One-to-many relationship between users and audit log entries. Every action performed by a user must be recorded in the audit trail (INV-AUTH-001, INV-FIN-003).

## Source

- **CON-AUTH-001** (User) — Aggregate root
- **CON-AUTH-008** (AuditLog) — Entity

## Constraints

- Audit logs are append-only — records must never be modified or deleted.
- Every action must be attributable to a user or system process (INV-AUTH-001).

## Bidirectional

- **User → AuditLogs:** A user has many audit log entries
- **AuditLog → User:** An audit log entry belongs to one user
