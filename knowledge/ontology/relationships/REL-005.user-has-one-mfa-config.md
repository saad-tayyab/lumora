# User has-one MFAConfig

## Definition

One-to-one optional relationship between users and their MFA configuration. Not all users will have MFA enabled.

## Source

- **CON-AUTH-001** (User) — Aggregate root
- **CON-AUTH-007** (MFAConfig) — Value object

## Constraints

- MFA secret must be encrypted at rest.
- Backup codes must be one-time use only.

## Bidirectional

- **User → MFAConfig:** A user has at most one MFA config
- **MFAConfig → User:** An MFA config belongs to one user
