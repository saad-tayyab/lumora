# InvoiceOverdue triggers DunningPolicy

## Definition

When an InvoiceOverdue event is emitted, the DunningPolicy is triggered to determine and execute the appropriate collection action based on how many days the invoice is past due.

## Source

- **CON-AR-012** (InvoiceOverdue) — Domain event
- **CON-AR-017** (DunningPolicy) — Policy

## Constraints

- The policy must be active for the dunning action to execute.
- INV-CROSS-002: Cross-context communication happens through domain events only.
