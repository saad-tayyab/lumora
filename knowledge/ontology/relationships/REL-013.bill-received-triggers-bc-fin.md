# BillReceived triggers BC-FIN

## Description

When a BillReceived event is emitted, it may trigger the creation of an accounts payable liability journal entry in the Financial Management bounded context.

## Source

- CON-AP-007 (BillReceived) — event

## Target

- BC-FIN (Financial Management) — journal entry

## Notes

- Cross-context communication happens through domain events only (INV-CROSS-002).
- The BC-FIN context consumes the event and posts the liability entry.
- No direct table access across bounded contexts (INV-CROSS-001).
