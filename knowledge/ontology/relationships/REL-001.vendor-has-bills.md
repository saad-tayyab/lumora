# Vendor has many Bills

## Description

A single vendor can have multiple bills issued against them over time. Each bill belongs to exactly one vendor.

## Source

- CON-AP-001 (Vendor) — one side

## Target

- CON-AP-003 (Bill) — many side

## Notes

- Vendor must be active for new bills to be created.
- Soft-deleted vendors retain historical bill records.
