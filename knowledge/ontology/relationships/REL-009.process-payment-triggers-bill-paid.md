# ProcessPayment emits BillPaid events

## Description

When a payment is processed, one BillPaid event is emitted per bill being paid.

## Source

- CON-AP-012 (ProcessPayment) — command

## Target

- CON-AP-009 (BillPaid) — event (one per bill)

## Notes

- Each BillPaid event references the specific bill and payment.
- Events are emitted after the VendorPayment is persisted.
