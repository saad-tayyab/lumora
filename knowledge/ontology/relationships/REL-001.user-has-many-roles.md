# User has-many Roles

## Definition

Many-to-many relationship between users and roles. A user can be assigned multiple roles, and a role can be assigned to multiple users. This implements Role-Based Access Control (RBAC).

## Source

- **CON-AUTH-001** (User) — Aggregate root
- **CON-AUTH-002** (Role) — Entity

## Constraints

- Roles are additive only (INV-AUTH-002) — assigning a role never removes existing permissions.
- Role assignments are logged in the audit trail.

## Bidirectional

- **User → Roles:** A user has many roles
- **Role → Users:** A role is assigned to many users
