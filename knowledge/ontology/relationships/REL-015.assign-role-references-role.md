# AssignRole references Role

## Definition

The AssignRole command assigns a role to a user. This is an additive operation only — roles are never revoked (INV-AUTH-002).

## Source

- **CON-AUTH-015** (AssignRole) — Command
- **CON-AUTH-002** (Role) — Entity

## Constraints

- INV-AUTH-002: Roles are additive only; no role can revoke base permissions.
- The assigning user must have admin privileges.
- The target role must exist and not be soft-deleted.

## Bidirectional

- **AssignRole → Role:** Command references a role
- **Role → AssignRole:** Role is assigned by this command
