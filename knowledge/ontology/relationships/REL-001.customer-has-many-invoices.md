# Customer has many Invoices

## Definition

A single customer can have multiple invoices over time. Each invoice belongs to exactly one customer.

## Source

- **CON-AR-001** (Customer) — Parent entity
- **CON-AR-002** (Invoice) — Child entity

## Constraints

- Every invoice must reference a valid, active customer.
- A customer can have invoices in any status (Draft, Sent, Paid, Overdue, Voided).
