# REL-035: Dashboard has-many KPI

## Definition

A Dashboard is composed of multiple KPI visualizations that provide real-time or near-real-time performance monitoring.

## Constraints

- Every Dashboard must display at least one KPI
- KPI must belong to the same tenant as the Dashboard
