# Role has-many Permissions

## Definition

Many-to-many relationship between roles and permissions. A role is a named collection of permissions. A permission can belong to multiple roles.

## Source

- **CON-AUTH-002** (Role) — Entity
- **CON-AUTH-003** (Permission) — Value object

## Constraints

- Permissions are immutable value objects.
- Roles are additive only (INV-AUTH-002).

## Bidirectional

- **Role → Permissions:** A role has many permissions
- **Permission → Roles:** A permission belongs to many roles
