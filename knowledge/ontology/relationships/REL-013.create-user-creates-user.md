# CreateUser creates User

## Definition

The CreateUser command is the entry point for creating a new user account. It validates input, creates the User aggregate, and emits the UserCreated event.

## Source

- **CON-AUTH-013** (CreateUser) — Command
- **CON-AUTH-001** (User) — Aggregate root

## Constraints

- Email must be unique within the tenant.
- Username must be unique within the tenant.
- Password must comply with PasswordPolicy (CON-AUTH-016).

## Bidirectional

- **CreateUser → User:** Command creates a user
- **User → CreateUser:** User is created by this command
