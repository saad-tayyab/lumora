# MFAConfig belongs-to User

## Definition

One-to-one relationship from MFAConfig to User. Each MFA configuration is associated with exactly one user.

## Source

- **CON-AUTH-007** (MFAConfig) — Value object
- **CON-AUTH-001** (User) — Aggregate root

## Constraints

- MFA secret must be encrypted at rest.
- Backup codes must be one-time use only.

## Bidirectional

- **MFAConfig → User:** An MFA config belongs to one user
- **User → MFAConfig:** A user has at most one MFA config (REL-005)
