# REL-045: ShareDashboard targets Dashboard

## Definition

The ShareDashboard command grants access to a Dashboard for specified users or groups at a defined permission level.

## Constraints

- Command must reference an existing Dashboard
- User must have admin or owner access to the Dashboard
