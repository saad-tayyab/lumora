# Session belongs-to User

## Definition

Many-to-one relationship from Session to User. Each session is associated with exactly one authenticated user.

## Source

- **CON-AUTH-004** (Session) — Entity
- **CON-AUTH-001** (User) — Aggregate root

## Constraints

- Sessions must expire after the configured timeout period (CON-AUTH-017).
- Revoked sessions cannot be reactivated.

## Bidirectional

- **Session → User:** A session belongs to one user
- **User → Sessions:** A user has many sessions (REL-002)
