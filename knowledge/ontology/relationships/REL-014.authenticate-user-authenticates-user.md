# AuthenticateUser authenticates User

## Definition

The AuthenticateUser command validates credentials and creates a session on success. It emits LoginAttempted for every attempt and UserAuthenticated on success.

## Source

- **CON-AUTH-014** (AuthenticateUser) — Command
- **CON-AUTH-001** (User) — Aggregate root

## Constraints

- Account must not be locked.
- Password must match the stored hash.
- MFA code must be valid if MFA is enabled.

## Bidirectional

- **AuthenticateUser → User:** Command authenticates a user
- **User → AuthenticateUser:** User is authenticated by this command
