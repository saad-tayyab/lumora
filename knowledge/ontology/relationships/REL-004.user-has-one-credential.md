# User has-one UserCredential

## Definition

One-to-one relationship between users and their credential record. The credential is isolated from the User aggregate to enforce security boundaries.

## Source

- **CON-AUTH-001** (User) — Aggregate root
- **CON-AUTH-006** (UserCredential) — Entity

## Constraints

- Password hashes must never be stored in plain text.
- Failed attempt counter must be reset on successful authentication.
- Credential must comply with PasswordPolicy (CON-AUTH-016).

## Bidirectional

- **User → Credential:** A user has one credential
- **Credential → User:** A credential belongs to one user
