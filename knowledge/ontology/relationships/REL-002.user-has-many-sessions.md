# User has-many Sessions

## Definition

One-to-many relationship between users and sessions. A user can have multiple concurrent sessions across different devices. Sessions are governed by the SessionTimeoutPolicy.

## Source

- **CON-AUTH-001** (User) — Aggregate root
- **CON-AUTH-004** (Session) — Entity

## Constraints

- Maximum concurrent sessions per user is governed by SessionTimeoutPolicy (CON-AUTH-017).
- Sessions must expire after the configured timeout.

## Bidirectional

- **User → Sessions:** A user has many sessions
- **Session → User:** A session belongs to one user
