# REL-041: KPIBreached triggers KPI

## Definition

When a KPI value crosses a defined threshold, the KPIBreached domain event is emitted for alerting and corrective action.

## Constraints

- Event must reference an existing KPI
- Threshold values must match the KPI's configuration
