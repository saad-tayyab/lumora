# DunningPolicy uses AgingBucket

## Definition

The DunningPolicy uses AgingBucket values to determine the appropriate escalation level for overdue invoices. Different aging buckets (e.g., 1-30 days, 31-60 days, 61-90 days, 90+ days) trigger different dunning actions.

## Source

- **CON-AR-017** (DunningPolicy) — Policy
- **CON-AR-007** (AgingBucket) — Value object

## Constraints

- The policy must define at least one dunning level per aging bucket.
