# Bill approval triggers BillApproved

## Description

When a bill passes the approval workflow, a BillApproved event is emitted.

## Source

- CON-AP-003 (Bill) — aggregate

## Target

- CON-AP-008 (BillApproved) — event

## Notes

- Only bills in pending_approval status can be approved.
- Approval is subject to the ApprovalWorkflow policy.
