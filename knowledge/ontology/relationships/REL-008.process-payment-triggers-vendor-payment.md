# ProcessPayment creates VendorPayment

## Description

When the ProcessPayment command is executed, it creates a new VendorPayment aggregate and emits BillPaid events.

## Source

- CON-AP-012 (ProcessPayment) — command

## Target

- CON-AP-002 (VendorPayment) — aggregate created

## Notes

- All referenced bills must be approved or partially paid.
- Payment amount must match the sum of amounts applied to bills.
