# CreateBill triggers Bill creation

## Description

When the CreateBill command is executed, it creates a new Bill aggregate and emits a BillReceived event.

## Source

- CON-AP-010 (CreateBill) — command

## Target

- CON-AP-003 (Bill) — aggregate created

## Notes

- Command validates vendor exists and is active.
- Bill number uniqueness is enforced per vendor.
