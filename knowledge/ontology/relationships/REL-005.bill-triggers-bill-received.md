# Bill creation triggers BillReceived

## Description

When a new bill is created, a BillReceived event is emitted to signal downstream processes.

## Source

- CON-AP-003 (Bill) — aggregate

## Target

- CON-AP-007 (BillReceived) — event

## Notes

- BillReceived is emitted after the Bill is persisted.
- The event carries the bill's key attributes for downstream consumption.
