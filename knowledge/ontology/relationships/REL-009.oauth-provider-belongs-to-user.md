# OAuthProvider belongs-to User

## Definition

Many-to-one relationship from OAuthProvider to User. Each OAuth provider link is associated with exactly one user.

## Source

- **CON-AUTH-005** (OAuthProvider) — Entity
- **CON-AUTH-001** (User) — Aggregate root

## Constraints

- A user can only have one link per provider type.
- OAuth tokens must be encrypted at rest.

## Bidirectional

- **OAuthProvider → User:** A provider link belongs to one user
- **User → OAuthProviders:** A user has many linked providers (REL-003)
