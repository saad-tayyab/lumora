# Knowledge Graph

> **Status:** Active  
> **Version:** 1.0.0  
> **Owner:** Knowledge Engineer

---

## Purpose

The knowledge graph captures relationships between all knowledge artifacts. It is maintained in three formats:

1. **Mermaid** — Visual diagrams in markdown
2. **YAML** — Structured data for tools
3. **JSON** — API consumption

---

## Structure

| File | Purpose |
|------|---------|
| `graph.yaml` | Source of truth for graph data |
| `graph.json` | Generated JSON format |
| `domain-map.mermaid` | High-level domain overview |
| `diagrams/` | Detailed diagrams |
| `INDEX.md` | Diagram index |
| `STANDARDS.md` | Graph standards |

---

*Standards: See `STANDARDS.md` for format specifications.*
